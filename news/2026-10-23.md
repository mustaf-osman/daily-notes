- [NVIDIA 开源 OpenShell：给一群自主 agent 修笼子](https://github.com/NVIDIA/OpenShell) — 295 分。定位是"agent 舰队的安全私有运行时"：每个 agent 跑在隔离沙箱里，文件访问、系统调用、每一条出网连接都在内核层过策略；agent 看不到真实凭据，只有发往白名单端点的请求才由运行时注入。最值得看的是第二层——策略变更在生效前先用形式化验证预演，一旦这次改动会让 agent 拿到新主机的凭据或调用新 API，就自动挂起等人工复核。Apache 2.0，支持 Linux、Apple Silicon macOS、WSL2。

## 💡 今日点评

**今天首页的主线是"给 agent 修笼子"，而且笼子开始用数学焊。** OpenShell 允许 agent 读文件、装包、调 API、用凭据——这些正是 agent 有用的原因，也是它危险的原因；NVIDIA 的解法不是靠 prompt 叮嘱，而是内核级策略加形式化验证预演，把"agent 自己改权限"这个最危险的动作变成必须人工复核的关卡。同一逻辑在 Anthropic 那条里更彻底：既然模型能写代码，就让它写证明，把"没有洞"从渗透测试的结论变成可检查的产物。这两件事必须同时成立——能力越强，边界越要可证明；否则 agent 只是把风险放大了一个数量级。

**Quad9 退出法国是今天最该被记住的一条，因为它不是技术事故。** 一个免费、非营利、靠公益基金运转的公共 DNS，被法院要求对本国用户返回被篡改的解析结果；它宁可退出市场也不干。这意味着"中立基础设施"在法律面前没有豁免权，版权执法可以直接把解析器当过滤器用。更现实的影响是：法国用户失去的不只是一个 DNS 服务，而是恶意域名拦截和隐私保护；而这类判决一旦被别国照抄，受伤的会是所有依赖公共解析服务的人。

**逆向工程那两条说明，"安全"已经彻底变成成本问题。** Switch 2 的入口并不玄妙——WebKit 的 n-day 加一个强制门户，难的只是把它稳定地做到 sysmodule 层；HackiOS 更是绕开苹果硬件，把开源内核和未修改的用户态搬到了安卓手机上。两件事都指向同一个结论：厂商能加的是攻击的时间成本，不是"不可破"的保证。对做机器人的直接启示也一样——RK3588 上要跑 agent，别再自己在 root 下跑再靠提示词约束，OpenShell 那套"凭据不进沙箱、策略变更先验证"的做法，才是能在现场交代得过去的方案。
