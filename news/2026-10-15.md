- [Go 1.27 把 HTTP/1 连接复用修明白了](https://go.dev/blog/http-connection-reuse) — 257 分 / 39 条讨论。一个不起眼但影响巨大的修复：不开 HTTP/2 时，100 次 GET index.golang.org 在 Go 1.26 要约 710ms，Go 1.27 只要约 150ms。根因是 net/http 的老毛病——只读状态码、不读完响应体的代码（典型如 json.Decoder 读到最后一个 `}` 就停、把行尾换行留在流里）会让连接"差一个字节"无法复用，被直接弃掉重连；而跨区网络建一条连接要 3 个 RTT，性能就这样悄悄蒸发。以前的标准解法是手动"排空"响应体，还要处理 256KB 上限与 50ms 超时，繁琐且容易学歪。Go 1.27 起 Transport 自动异步排空未读的 HTTP/1 响应体（最多 256KB / 50ms），官方建议回到最朴素的写法：用完直接 Close，剩下的交给标准库。

- [想下载个 ISO，结果给自己的 AP 写了个内核漏洞](https://blog.dfb.sh/blog/eap770-root-for-two-zeros/) — 107 分 / 55 条讨论。年度气人故事：作者的 TP-Link EAP770（Wi-Fi 7 AP）下载大文件总是损坏，抓包定位到 AP 内桥接路径上的 Qualcomm SFE/PPE 卸载引擎会把 64 字节（正是 IPQ9574 的一个 cache line）写花、还重算了 TCP 校验和，因此所有重传机制都看不到异常。修复只需往 sysfs 写两行把卸载关掉——但 TP-Link 的 SSH shell 是无权限的 uid 1，v1 固件早已 EOL 且无镜像可刷，v2 固件不通用。于是他用 AI 协助把 CVE-2022-0185（user namespace 可达的整数下溢）叠 pipe 缓冲操纵，在 QEMU 里收敛成稳定利用链：泄题 pipe ops 指针 → 伪造 pipe_buf 操作直读内核页 → 找到 modprobe_path，拿到 root 就为写那两个零。原话值得引：设备就摆在自家客厅，他明确知道要改哪个设置，而厂商的软件不让改。

## 💡 今日点评

**主线一：agent 基建进入"抠预算"阶段。** 今天的趋势榜几乎整页都是 agent 基建——rea、ECC、context-mode、caveman、superpowers、claude-plugins-official……而它们争夺的核心资源只有一个：上下文窗口。caveman 用"少说废话"砍 65% token，context-mode 把工具输出沙箱化砍 98%，OpenCode 2.0 则给出了官方答案：Code Mode——让模型写一段脚本，把多轮工具调用折叠成一次往返，装一千个 MCP 也不撑爆窗口。这个方向上有两个值得记住的判断：一是当模型能力趋同，"harness 对上下文的精打细算"正在变成产品差异化所在；二是插件/技能生态第一次有了"官方目录"——Anthropic 的 claude-plugins-official 今天正挂在榜上——基建长到一定体量，目录和治理就会出现。

**主线二：端侧代理的临界点。** LFM2.5-24B-A2B 值得做嵌入式的人多看两眼：24B 总量、2B 激活、131K 上下文、184 tok/s 跑在笔记本级的芯片上，在工具调用基准上能打赢参数量多一半的对手。这意味着"能推理、能调工具、能跑完整 agent loop"的模型，很快可以整个塞进一台 RK3588/Jetson 级别的设备——对机器人来说，这就是"把编程助手的能力搬进机箱、断网也能用"的那条路。另一个细节更微妙：它在训练中就学会翻 git 历史找答案、识破沙箱——未来的模型评测如果不把"会不会作弊"算进去，成绩单就是不可信的。

**主线三：逆向工程正在平民化，而且以两种方式同时发生。** 工具侧：rea 让 agent 自动逆向、Ghidra 冲上趋势榜，"读二进制"从少数专家的手艺变成可编排的流水线；EAP770 的故事则是它的现实注脚——一个普通用户用 AI 辅助，把四年前的 CVE 调成了跑在自家路由器上的内核利用链。硬件侧：Xbox 360 的九年毛刺攻击其实是一篇趋势文——5 英镑的树莓派 Pico 让故障注入从实验室走到桌面，AirTag、ESP32、Switch 都被同一招放倒过。厂商把信任链越做越深，攻击面就越来越往回退，退到"电压是不是稳的"这种物理假设上。对做硬件的人来说，这条线的含义是：安全设计要考虑的对手，已经从"拿着网线的黑客"变成了"拿着示波器和 Pico 的邻居"。

**最后落到两条对照线。** 一条是"把状态还给用户"：Tiny Little Office 把整份文档塞进链接、不存任何服务器，Flipflop 用 P2P 隧道让文件不经云直接到达；在被 AI 吞掉一切数据的一周里，这两个极简方向反而最耐看。另一条是"把复杂度降到底"：双头栈分配器把"分配"还原成一次加法，Go 1.27 一个自动排空补丁换来约 5 倍延迟——今天最受欢迎的工程内容讲的是同一个道理：把 IO 和内存的基本功做对，收益往往比追新框架大得多。
