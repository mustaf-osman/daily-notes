## 💡 今日点评

今天分量最重的不是某项新技术，而是一组数字：git.kernel.org 的维护者算了笔账——为 AI 爬虫渲染 commit 页面花的 CPU，已经超过给所有真实用户（包括 git clone）服务的总和。这是"爬虫之害"第一次从抱怨变成可审计的账单：开源基础设施正在用最昂贵的方式，免费补贴闭源大模型的训练。当开放社区的服务器把 14 个核心常年"上贡"给爬虫时，robot 协议之争就从道德辩论升级成了经济学问题——接下来大概率会看到更多基础设施加防护墙、上验证码，甚至对爬虫收费。开放网络和 AI 数据饥渴之间的裂缝，正在变成一条明算账的分界线。

另一条值得记下的线是"非自回归"回潮：DeepMind 研究员的长文指出，连续扩散语言模型在被离散扩散压制数年后重新热闹起来。如果扩散式生成在推理质量、可控性上真正追上自回归模型，"逐 token 生成"这个 LLM 的基本假设就可能松动——这对架构竞赛的意义不亚于当年 Transformer 之争。

最后看 GitHub 榜，AI agent 生态依然是绝对主角，但形态在分化：一边是"让 ChatGPT 给 Codex 当大脑"的模型嫁接工具，一边是通知收件箱、内存取证这类扎实的基础设施项目。喧嚣之下，真正被每天使用的东西才会留下来——这个判断，在爬虫啃食开源的今天，比任何时候都更值得记住。
