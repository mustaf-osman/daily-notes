- [Roku 把全部开发者仓库从 GitHub 搬到 GitLab](https://blog.roku.com/developer/gitlab-move) — 259 分，169 条评论。迁移覆盖开发者文档、示例应用和 RSG 2.0 SDK 的工具链，仓库名一个没改，github.com/rokudev/<repo> 直接对应 gitlab.com/rokudev/<repo>，老克隆改一下 remote 就行。官方公告只说"集中到一个地方"，没给原因，于是评论区自己补：有人发现 Roku 的 README 里还写着"欢迎来到我们的 GitHub 仓库"，有人借机清算微软治下的 GitHub 越来越不可靠、被全天候运行的智能体提交淹没。配套消息是 RSG 2.0 SDK 10 月 29 日公测，届时开始在 GitLab 接合并请求。

- [Goose：没有堆、没有垃圾回收、没有生命周期标注的系统语言](https://aardappel.github.io/goose/) — 236 分，158 条评论。作者 Wouter van Oortmerssen 是 Lobster 语言的作者，这套设计的核心是把所有动态值内联在编译器静态分配的数据栈上：作用域结束即释放，增长只推进指针且已有引用不失效，所以释放一个百万元素的深层嵌套结构只是一次写操作。自报 16 项基准里比惯用 C++ 快 3.3 倍、比手写优化 C++ 快 1.16 倍、比最好的安全 Rust 快 1.12 倍，内存分别少 1.9、1.3、1.2 倍。最值得读的是文末专设的"Use of AI"一节：语言设计、编译器设计是他的，而编译器实现、基准测试、示例和文档几乎全部由 Claude 完成，他让模型照抄自己另一个编译器 Lobster 的结构。HN 上 Carmack 评价"多数据栈加可增长字段，把'很多事可以这么干'变成了'基本什么都能这么干'"，也有人直说读起来像 AI 垃圾、找不到不用 C++ 的理由。

- [Dan Luu：我们该把软件做得更有野心一点](https://danluu.com/ambitious/) — 150 分。他从 Michael Malis 用 Rust 重写 Postgres（pgrust）讲起，先承认自己第一反应也是"又一个氛围编程的垃圾"——现在满地都是 AI 生成、永远跑不起来的项目，这种怀疑很合理。但 Malis 的测试扎实到在 Postgres 里挖出了真 bug：SP-GiST 的数值 bug 会让合法操作失败、JSONPath 的格式缓存 bug 会返回错误结果、pgcrypto 有个让后续操作失败的洞、字典加载器有多处内存安全问题、money 类型还有溢出。结论不是"AI 写的也行"，而是：哪怕 pgrust 最后失败，光是认真重写这一遍就已经让 Postgres 变好了；野心不是不看成本地蛮干，而是敢挑那些失败了也有价值的题目。

- [美国创意产业四年蒸发 20 万个岗位，AI 该背多少锅](https://www.apricitas.io/p/ai-and-the-fall-of-the-creative-class) — 128 分，108 条评论。Apricitas 的 Joseph Politano 算账：过去四年美国创意行业少了 20 多万个岗位，最近一年约 5 万且在加速，烈度只有 2001 和 2008 两次衰退可比——但今天并没有全面衰退。最惨的是电影与录音，四年丢掉 10 万以上、接近该行业总就业的三分之一，今夏触底时低于 2008 年以来的任何时点；出版其次，少了 7 万多。他认为最像 AI 指纹的证据是结构性的：所有数字艺术子行业都在掉，线下演出却在健康增长。但他也老实承认归因很难——影视整合、制作外包、传统媒体被社交创作者替代都在同时发生，而且媒体公司为了保住版权诉讼的立场，普遍不肯承认自己在用 AI。

- [在线收听美军核力量的应急行动指令](https://missileer.watch) — 111 分，76 条评论。一个业余无线电项目，实时收听并转录 11175 kHz 上的高频全球通信系统广播，也就是发给核力量的 EAM（应急行动指令）。这类广播是单向、短促、编码过的字符组，靠一次性密码本解读，平时天天在播，既是演练也是"随时能用"的证明。网站把录音和解码结果以 CC0 释出，不装追踪 cookie，页面自己也标注当前显示的是开发用示例数据而非实时流量。评论区气氛很有意思：有人贴出经典的"Skyking, Skyking, do not answer"，也有人认真讨论这套系统为什么至今还靠短波。

- [SpeedCrunch 1.1 发布](https://www.speedcrunch.org/) — 73 分。开源高精度科学计算器的新版本：最高 50 位精度、支持复数、140 多个函数、单位与常量、向量和矩阵，历史记录可重写、每个结果能单独设格式，支持多标签/多窗格会话，40 多种翻译和 40 多套配色。它的定位十几年没变——不画函数图、不做符号推导，只把"算得准、键盘输入快"做到极致。

- [给硬件黑客做的廉价双目立体视觉板](https://rootkitlabs.com/2026/10/06/i-built-a-stereo-vision-board-for-hardware-hackers/) — 29 分。作者用瑞芯微 RV1103 做了块开源双目板：单核 1.1 GHz Cortex-A7、64 MB DDR2、MIPI CSI-2，塞进 QFN-88 封装，四层板就够。板子自带 Linux，上电后直接在板上做深度计算，再通过串口把结果发给 Arduino 之类的下位机做避障或导航。动机很直接：现成深度相机要么贵要么封闭，而机器人近距避障其实只需要一路低功耗的深度。文章把硬件、固件、软件和打样踩的坑全写了——SoC 订错型号、镜头孔钻成 1.8 mm 而不是 2.2 mm。

## 💡 今日点评

**今天首页其实在吵同一件事：AI 把"做出像样东西"的门槛拉平之后，剩下的分水岭是验收。** 悲观的一条是 Apricitas 的就业数据——创意行业四年少 20 万岗位，且只有数字艺术在掉、线下演出在涨，这个分化比任何公司声明都更像 AI 的指纹。乐观的一条是 Goose 和 pgrust：一个由 AI 几乎写完的编译器，一个用 Rust 重写 Postgres 的疯狂项目。两者能站住脚的原因完全一样——作者没有把"AI 写的"当卖点，而是拿可复现的基准、可验证的测试去顶。Goose 专门写一节交代 AI 参与程度，Dan Luu 判断 pgrust 的标准也不是"是否 AI 写"而是"测试是否扎实到能挖出 Postgres 自己的 bug"。反过来看 Roku 搬仓库和评论区的火气：当平台上全是 24 小时不间断的智能体提交，代码托管这个最底层的基础设施也开始被"AI 通胀"反噬——信号被噪声淹没，用户就用脚投票。

**GitHub 榜单则把开发者的真实焦虑摊开了：六条里五条在解决"怎么驯服智能体"。** 压缩它的输入（headroom）、约束它的输出（ponytail 的少写代码）、给它建索引（graphify）、把审计流程固化下来（Cloudflare 的安全技能）、把多个智能体编排成流水线（orca）。这已经不是尝鲜，而是很具体的工程需求：上下文太贵、输出太水、行为不可验证。对做嵌入式和机器人的人来说，今天最值得记的两条反而是小的：RV1103 那块双目板证明"几十块钱的芯片 + 串口"就能给下位机一路可用的深度，以及 Goose 那套"无堆 + 数据栈"的内存模型——它的基准还是作者自报的 16 项，需要独立复现，但如果成立，实时控制场景里少一次内存分配就是少一次不可预测的抖动。
