## 💡 今日点评

如果用一个词总结今天，是**"agent 的配件化"**。榜单前排一半是技能与外壳：Cloudflare 把安全审计方法论打包成 skill、Addy Osmani 发 agent-skills 合集、ECC 自称"harness 优化系统"，连 HN 上都有 HarnessTax 这种专门测算"外壳对编码 agent 影响多大"的项目。行业开始形成共识：模型能力趋同之后，胜负手转移到了 harness——上下文怎么组织、技能怎么加载、记忆怎么存、权限怎么给。讲人话：发动机大家都能买到了，现在拼的是变速箱和底盘。更值得注意的是，"技能"正在变成一种知识分发渠道——安全公司把专家审计流程做成 agent 能加载的技能卡，这比发十份白皮书都有效。

第二条线是**"更小更便宜"的技术走廊全面铺开**：4B 小模型用 RL 反超 Postgres 规划器 81%、三值 LLM 论文继续冲低比特天花板、colibri 让消费级硬件流式跑 MoE、英伟达把 Rust 引进 GPU kernel。上层 agent 越铺越多，下层每一层的成本都在被死磕。对做嵌入式和机器人的人：算力受限设备上的本地智能，窗口正在变大——值得把"小模型在本地到底能做到什么"重新评估一遍。

最后一条彩蛋：GitHub Trending 里今天夹着个 [rlaope/oh-my-hermes](https://github.com/rlaope/oh-my-hermes)（2.5k 星）——"All in one plugin for Hermes Agent"。你天天在用的工具，社区开始有人给它写插件了。
