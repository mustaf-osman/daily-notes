- [sshole：一行 `*` 埋了十年的 SSH 认证漏洞，2524 分今日第一](https://sshhole.com) — 站点名就一个梗：OpenSSH 在 **musl libc** 系统（Alpine、OpenWrt、Buildroot、Yocto，以及你 pull 过的一大半 Docker 镜像）上，从 2016 年起就有一个认证逻辑缺陷。本该**完全禁止密码登录**的账户——root、只用密钥的部署用户、LDAP 用户、Alpine 官方云镜像的默认用户——只要密码长度超过 256 个字符，就会被当成登录成功。根子是 `/etc/passwd` 里用来占位的 `*`（自 1980 年 Bill Joy 那个 `daemon` 账户起的约定）在新代码路径里被错误处理。616 条评论的共识：不是你被黑了，是"默认镜像就长这样"。

## 💡 今日点评

**今天两条最重的新闻，都在讲同一件事：你以为安全的地方，其实一直没有设防。**

sshole 和 Claude Code 的邮箱泄露，表面上一个是 OpenSSH 的认证 bug，一个是应用把用户标识写进请求头，但本质相同——**安全假设和实际代码脱节**。`/etc/passwd` 里那个 `*` 是为了"永不可登录"设计的，可新代码路径把它当成了普通字符串比较，于是"任意 256 字符以上密码"就能进 root。Claude Code 更直白：把邮箱塞进 User-Agent 是"为了标识客户端"这种顺手的做法，代价是把用户的身份主动分发出去。做后端和固件的人应该把这两条记在心里：**认证和隐私的默认值，往往是几十年前的临时约定，而现代代码没读懂它。** 这和我碰过的 CAN 总线、PMIC 上下电时序是同一类问题——协议约定和实现之间那条缝，平时看不出来，出了就是全穿。

第二条线是**开源在"性价比前沿"上被闭源反超**。Village 的数据很扎眼：半年前开源权重还能在 41% 的价位点称王，现在只剩 3%。与此同时 GitHub 趋势榜今天几乎被"给智能体用的基础设施"占满——auto-ontology、agent-desktop、google/skills、VibeVoice。这两件事合起来是一个判断：**模型能力本身在向闭源收敛，但围绕模型搭"手脚和上下文"的工程正大量开源化**。对做端侧的人和团队来说，路线其实更清楚了：没必要死磕自训一个开源大模型去拼性能，把精力放在"怎么把闭源模型接进自己的系统、管好自己的数据和设备"更划算。Inkling 那种"594B 总参数、17B 激活"的 MoE 也在暗示同一个方向——**比拼的不是谁参数多，是谁每个 token 花得更值**，这跟嵌入式世界里"算力预算有限时怎么调度"是同一个命题。

第三条小线：NVIDIA 下场做裸金属 GPU 的 K8s 管理面。云之外的算力（自建、边缘、私有）正在长出自己的一套编排栈，硬件方不再只卖卡。这条今天分数最低，但我认为是三个月后回看会更重要的一条。
