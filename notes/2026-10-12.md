## 💭 技术随想：万向节死锁——转到某个角度，三个旋钮突然只剩两个管用

机器人、无人机、相机云台，都要回答同一个问题："我现在朝哪儿？" 工程师最顺手的答案，是拿三个角度去记账——**扭头多少（yaw）、抬头多少（pitch）、歪头多少（roll）**。这套说法（欧拉角）的优点是每个数字都能在脑子里画出画面："把 yaw 拧 5 度"，人话，谁听都懂。调参、写报告、跟同事比划，全是它。

但三个角度去描述三个方向的转动，有一个出了名的死角。转到某些特定姿态（比如机头指向正上方、正下方）时，三个旋钮里有两个会突然"焊"在一起：**拧哪个，效果都一模一样**；你想只动其中一个，物理上办不到。这就是大名鼎鼎的**万向节死锁**（gimbal lock）。名字听着像机械事故，其实不是哪根轴卡住了——转动机构好好的、姿态也好好的，塌的是**描述方式本身**：坐标在这一个点上掉了一个维度。自由度明明还是三，账本上只剩两栏能记。

要说清这事，得先看老式云台的构造：三个金属环一个套一个，外环转偏航、中环转俯仰、内环转横滚，各管各的。可一旦俯仰转到 90°（机头朝天），外环和内环的**转轴正好重合**——两个环在转同一根轴。像机场的旋转门和推拉门装进了同一个门框：看着还是两扇门，实际只能开一次。从这一秒起，"拧外环"和"拧内环"是同一个动作，第三个旋钮成了摆设。

这套"三个旋钮"的记账法，毛病不止死锁这一个点，而是**三条连着的问题**，今天用四个实验逐个对质：

**一、反解不唯一。** 在死锁点上，无穷多组角度命令对应同一个姿态。"调到 yaw=25°"还是"调到 yaw=0°"？——两个命令，一秒不差地一样。你自己都分不清哪个是"对的"。

**二、旁边也不干净：数字放大。** 离死锁越近，"身体转一点点"翻译成"角度变多少"的账越离谱：换算里藏着一个除以 cos(pitch) 的因子，俯仰 89.99° 时它是 **5729 倍**。传感器上一点噪声，经过这个因子就能放大几千倍砸进控制器——这就是很多姿态解算"平时好好的、一抬头就发疯"的机理。

**三、跨过死锁线：物理连续、数字跳楼。** 姿态从俯仰 89.999° 平滑地走到 90.001°（物理上只挪了 0.002°），报表上的 yaw 和 roll 会**各自跳 180°**。数字和物理脱钩，谁拿这串数字去做差值、做微分，谁就接到一把假的"剧变信号"。

解法也早就有了，就是**四元数**：用四个数来记三个自由度。多出来的那一位不是浪费——它记的是"绕法"：`q` 和 `-q` 描述同一个姿态，就像"从正面转 359°"和"从背面转 1°"，殊途同归。它的更新公式里**没有任何除法、没有 cos(pitch) 这种会踩到零的分母**，翻跟头也好、对准天顶也好，公式长一个样。当年阿波罗飞船的主惯性平台特意上到"第四个环"来绕开死锁；现代的答案更便宜——多带一个数就行了。

连"插值"也要看姿态、不能看数字：从 yaw 170° 转到 -170°，物理上最近的路只有 20°，但对数字做均匀插值会让它**绕远路 340°**；四元数的 slerp 会自动挑短边，稳稳走 20°。云台扫过、机器人甩头，插值算法选错，"平滑过渡"就变成"多转一圈"。

工程上的惯例因此分成两层：**给机器算的账本用四元数**（姿态解算、积分、插值、控制回路都在这一层），**给人读的报表翻译成欧拉角**（只在最后一步翻译，绝不拿报表当账本再算回去）。IMU 输出的主流就是四元数，而界面上显示"偏航 12.3°"——报表和账本各司其职。阈值心算也简单：俯仰 60° 时放大因子已经 2 倍，85° 时 11 倍，日常小角度、不朝天顶的展示场景，用欧拉角问题不大；全姿态的（无人机翻滚、机器人跌倒爬起、云台扫天顶），第一天就该上四元数。

回头看，死锁不是物理的锁，是**描述的锁**。坐标是我们给自己配的眼镜，物理世界并不在乎这副眼镜有没有盲区。下次再遇到"参数怎么调都没反应"，不妨先怀疑眼镜，而不是怀疑世界。

## 🧩 今日代码片段：姿态实验室——四组现场实验

四个小实验，纯 Python 标准库（无需任何第三方包），本机 Python 3.11.15 真实运行，输出为真实运行结果：① 死锁现场——两个"不同"的命令，同一个姿态；② 1/cos(pitch) 放大因子表；③ 跨过死锁线——物理 0.002°，报表跳 180°；④ 两种插值对质——数字直线 vs 四元数 slerp。约定：ZYX 顺序，R = Rz(yaw)·Ry(pitch)·Rx(roll)，死锁在 pitch = ±90°。

```python
# -*- coding: utf-8 -*-
"""姿态实验室：万向节死锁与四元数 —— 四组实验（纯标准库，真实可运行）

约定：ZYX 欧拉角 = 先绕 Z 偏航(yaw)、再绕 Y 俯仰(pitch)、最后绕 X 横滚(roll)
      旋转矩阵 R = Rz(yaw)·Ry(pitch)·Rx(roll)，作用于列向量：v' = R·v
      死锁发生在 pitch = ±90°
"""
import math
import sys

try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass

DEG = math.degrees
RAD = math.radians


def rot_x(t):
    c, s = math.cos(t), math.sin(t)
    return [[1, 0, 0], [0, c, -s], [0, s, c]]


def rot_y(t):
    c, s = math.cos(t), math.sin(t)
    return [[c, 0, s], [0, 1, 0], [-s, 0, c]]


def rot_z(t):
    c, s = math.cos(t), math.sin(t)
    return [[c, -s, 0], [s, c, 0], [0, 0, 1]]


def mm(A, B):
    return [[sum(A[i][k] * B[k][j] for k in range(3)) for j in range(3)] for i in range(3)]


def mv(A, v):
    return [sum(A[i][k] * v[k] for k in range(3)) for i in range(3)]


def euler_mat(yaw, pitch, roll):
    return mm(mm(rot_z(RAD(yaw)), rot_y(RAD(pitch))), rot_x(RAD(roll)))


def mat_euler(R):
    """反解 ZYX 欧拉角（度）。theta 被限制在 [-90°, 90°] —— 越过 90° 时数字会跳变"""
    theta = math.asin(max(-1.0, min(1.0, -R[2][0])))
    if abs(math.cos(theta)) > 1e-9:
        yaw = math.atan2(R[1][0], R[0][0])
        roll = math.atan2(R[2][1], R[2][2])
    else:
        yaw = math.atan2(-R[0][1], R[1][1])   # 死锁：yaw/roll 分不开，只能约定 roll = 0
        roll = 0.0
    return DEG(yaw), DEG(theta), DEG(roll)


def maxdiff(A, B):
    return max(abs(A[i][j] - B[i][j]) for i in range(3) for j in range(3))


def show_mat(R):
    for row in R:
        print("      [ " + "  ".join(f"{x:+.6f}" for x in row) + " ]")


def show3(v, p=6):
    return "(" + ", ".join(f"{x:+.{p}f}" for x in v) + ")"


def fmt_euler(t):
    return f"(yaw {t[0]:+8.2f}°, pitch {t[1]:+8.3f}°, roll {t[2]:+8.2f}°)"


# ---------------- 四元数 ----------------
def q_mul(a, b):
    w1, x1, y1, z1 = a
    w2, x2, y2, z2 = b
    return (w1 * w2 - x1 * x2 - y1 * y2 - z1 * z2,
            w1 * x2 + x1 * w2 + y1 * z2 - z1 * y2,
            w1 * y2 - x1 * z2 + y1 * w2 + z1 * x2,
            w1 * z2 + x1 * y2 - y1 * x2 + z1 * w2)


def q_axis(axis, deg):
    n = math.sqrt(sum(c * c for c in axis)) or 1.0
    ax, ay, az = (c / n for c in axis)
    h = RAD(deg) / 2
    s = math.sin(h)
    return (math.cos(h), ax * s, ay * s, az * s)


def q_euler(yaw, pitch, roll):
    return q_mul(q_mul(q_axis((0, 0, 1), yaw), q_axis((0, 1, 0), pitch)), q_axis((1, 0, 0), roll))


def q_norm(q):
    n = math.sqrt(sum(c * c for c in q))
    return tuple(c / n for c in q)


def q_angle(q1, q2):
    """两个姿态之间的物理夹角（度）"""
    d = abs(sum(a * b for a, b in zip(q1, q2)))
    d = max(-1.0, min(1.0, d))
    return DEG(2 * math.acos(d))


def mat_from_q(q):
    w, x, y, z = q
    return [
        [1 - 2 * (y * y + z * z), 2 * (x * y - w * z), 2 * (x * z + w * y)],
        [2 * (x * y + w * z), 1 - 2 * (x * x + z * z), 2 * (y * z - w * x)],
        [2 * (x * z - w * y), 2 * (y * z + w * x), 1 - 2 * (x * x + y * y)],
    ]


def q_slerp(a, b, t):
    d = sum(x * y for x, y in zip(a, b))
    if d < 0:                       # q 与 -q 是同一个姿态：走短边
        b = tuple(-x for x in b)
        d = -d
    if d > 0.9995:
        return q_norm(tuple(x + t * (y - x) for x, y in zip(a, b)))
    th0 = math.acos(max(-1.0, min(1.0, d)))
    th = th0 * t
    s0, s1, st = math.sin(th0 - th), math.sin(th), math.sin(th0)
    return tuple((a[i] * s0 + b[i] * s1) / st for i in range(4))


LINE = "=" * 66

# ================================================================
print(LINE)
print("实验1：转到 90° —— 三个旋钮突然只剩两个管用")
print(LINE)
Ma = euler_mat(25, 90, 0)
Mb = euler_mat(40, 90, 15)
print("  姿态 A = (yaw=25°, pitch=90°, roll=0°)：")
show_mat(Ma)
print("  姿态 B = (yaw=40°, pitch=90°, roll=15°)  （yaw 和 roll 各自 +15°）：")
show_mat(Mb)
print(f"  A 与 B 矩阵最大元素差 = {maxdiff(Ma, Mb):.2e}  ← 浮点噪声级：是同一个姿态！")
print(f"  物理夹角实测 = {q_angle(q_euler(25, 90, 0), q_euler(40, 90, 15)):.3f}°")
print()
v1, v2 = (1, 0, 0), (0, 0, 1)
print(f"  拿两根探针方向去试：v1={v1} v2={v2}")
print(f"    A 转动 v1 → {show3(mv(Ma, v1), 5)}     B 转动 v1 → {show3(mv(Mb, v1), 5)}")
print(f"    A 转动 v2 → {show3(mv(Ma, v2), 5)}     B 转动 v2 → {show3(mv(Mb, v2), 5)}")
print("    （v1 两条结果一样、v2 也一样：两个'不同'的角度命令 = 同一件事）")
print()
Mc = euler_mat(0, 90, -25)
print(f"  再来一个 (yaw=0°, pitch=90°, roll=-25°)：与 A 的最大元素差 = {maxdiff(Ma, Mc):.2e}")
print("  → 在 90° 上：yaw=25/roll=0 与 yaw=0/roll=-25 完全等价，只有 (roll-yaw) 算数")
print()
Md = euler_mat(25, 89, 0)
Me = euler_mat(40, 89, 15)
print(f"  退到 pitch=89°：(25,89,0) 与 (40,89,15) 的最大元素差 = {maxdiff(Md, Me):.6f}")
print(f"    物理夹角实测 = {q_angle(q_euler(25, 89, 0), q_euler(40, 89, 15)):.3f}°   ← 又变成两个不同姿态")
print(f"    探针 v2：{show3(mv(Md, v2), 5)}  vs  {show3(mv(Me, v2), 5)}")
print("  → '死锁'只在 90° 这一个点上，但越靠近它，坐标越'病'（下个实验量化）")

# ================================================================
print()
print(LINE)
print("实验2：接近 90° 时的翻译爆炸 —— 1/cos(pitch) 这张账单")
print(LINE)
print("  欧拉角速率与机体角速度的关系（ZYX 顺序，经典式子）：")
print("      yaw_rate = (q·sin(roll) + r·cos(roll)) / cos(pitch)")
print("  取 roll=0、机体自己绕 z 轴以 1°/s 匀匀地转，需要写出的 yaw_rate = 1/cos(pitch)：")
print()
print("      pitch      需要的 yaw_rate（°/s）")
for pitch in (0, 60, 80, 85, 89, 89.9, 89.99):
    print(f"      {pitch:>6.2f}°     {1.0 / math.cos(RAD(pitch)):>13.2f}")
print(f"      {90.0:>6.2f}°     {'∞（除数为 0）':>13}")
print("  → 同样的身体转动，越接近 90°，数字账本越大；传感器一点噪声会被放大几千倍")
print()
print("  四元数的更新公式：q_new = normalize( q ⊗ Δq(ω·dt) )   —— 通篇没有除法，")
print("  也没有 cos(pitch) 这种会踩到 0 的项；任意姿态下公式长一个样。")

# ================================================================
print()
print(LINE)
print("实验3：跨过 90° 线 —— 物理挪了 0.002°，报表跳了半圈")
print(LINE)
R0 = euler_mat(40, 89.999, 15)     # 差一点到天顶
R1 = euler_mat(40, 90.001, 15)     # 刚过天顶一点
e0, e1 = mat_euler(R0), mat_euler(R1)
q0, q1 = q_euler(40, 89.999, 15), q_euler(40, 90.001, 15)
print(f"  同一个连续动作：pitch 从 89.999° 走到 90.001°（物理上只挪了 {q_angle(q0, q1):.3f}°）")
print(f"    欧拉报表①  {fmt_euler(e0)}")
print(f"    欧拉报表②  {fmt_euler(e1)}")
print(f"    → yaw 跳了 {(e1[0] - e0[0]):+.1f}°、roll 跳了 {(e1[2] - e0[2]):+.1f}°（各自半圈），pitch 纹丝不动")
print(f"    四元数账本  q① = ({q0[0]:+.7f}, {q0[1]:+.7f}, {q0[2]:+.7f}, {q0[3]:+.7f})")
print(f"                q② = ({q1[0]:+.7f}, {q1[1]:+.7f}, {q1[2]:+.7f}, {q1[3]:+.7f})")
print(f"    分量最大变化 = {max(abs(a - b) for a, b in zip(q0, q1)):.2e}（安安静静）")
print()
print("  对照：用四元数走 90 个 1° 的小步（控制循环里就是这么积分姿态的）：")
q = q0
prev = q
worst = 0.0
for _ in range(90):
    q = q_norm(q_mul(q, q_axis((0, 1, 0), 1.0)))
    worst = max(worst, abs(q_angle(prev, q) - 1.0))
    prev = q
print(f"    每步物理转角最大偏差 {worst:.2e}°，全程四元数范数 = {math.sqrt(sum(c*c for c in q)):.12f}")
print("    → 从头到尾没有任何一步要'除以一个快变成 0 的数'：账本不抖，抖的只是报表")

# ================================================================
print()
print(LINE)
print("实验4：插值——'数字上走得直' ≠ '姿态上走得顺'")
print(LINE)
A = q_euler(170, 0, 0)
B = q_euler(-170, 0, 0)
print(f"  目标：从 (yaw 170°) 转到 (yaw -170°)，物理上最近的路只有 {q_angle(A, B):.2f}°")
print()
print("  ① 直接对数字线性插值（yaw 170 → -170，匀 10 步）：")
prev = q_euler(170, 0, 0)
tot = 0.0
steps_euler = []
for i in range(1, 11):
    yaw = 170 + (-170 - 170) * i / 10.0
    q = q_euler(yaw, 0, 0)
    steps_euler.append(q_angle(prev, q))
    tot += q_angle(prev, q)
    prev = q
print(f"     每步物理转角：{steps_euler[0]:.1f}°、{steps_euler[1]:.1f}°、{steps_euler[2]:.1f}° ...")
print(f"     全程总共绕了：{tot:.0f}°   ← 数字上匀速直线，姿态上多绕了 320° 的远路")
print()
print("  ② 四元数 slerp（自动走两个姿态之间的短边）：")
prev = A
tot = 0.0
steps = []
for i in range(1, 11):
    q = q_slerp(A, B, i / 10.0)
    steps.append(q_angle(prev, q))
    tot += q_angle(prev, q)
    prev = q
print(f"     每步物理转角：{steps[0]:.1f}°、{steps[1]:.1f}°、{steps[2]:.1f}° ...")
print(f"     全程总共绕了：{tot:.0f}°   ← 走了物理上真正最短的那条路")
print()
print("  一句话：欧拉角是'给人读的报表'，四元数是'给机器算的账本'。")
print("  报表好看，但报表上做插值、做反解、做控制，就是在薄冰上跳舞。")
```

```text
  同一个连续动作：pitch 从 89.999° 走到 90.001°（物理上只挪了 0.002°）
    欧拉报表①  (yaw   +40.00°, pitch  +89.999°, roll   +15.00°)
    欧拉报表②  (yaw  -140.00°, pitch  +89.999°, roll  -165.00°)
    → yaw 跳了 -180.0°、roll 跳了 -180.0°（各自半圈），pitch 纹丝不动
    四元数账本  q① = (+0.6903510, -0.1530431, +0.6903401, +0.1530488)
                q② = (+0.6903401, -0.1530488, +0.6903510, +0.1530431)
    分量最大变化 = 1.09e-05（安安静静）

  对照：用四元数走 90 个 1° 的小步（控制循环里就是这么积分姿态的）：
    每步物理转角最大偏差 6.11e-12°，全程四元数范数 = 1.000000000000
    → 从头到尾没有任何一步要'除以一个快变成 0 的数'：账本不抖，抖的只是报表

==================================================================
实验4：插值——'数字上走得直' ≠ '姿态上走得顺'
==================================================================
  目标：从 (yaw 170°) 转到 (yaw -170°)，物理上最近的路只有 20.00°

  ① 直接对数字线性插值（yaw 170 → -170，匀 10 步）：
     每步物理转角：34.0°、34.0°、34.0° ...
     全程总共绕了：340°   ← 数字上匀速直线，姿态上多绕了 320° 的远路

  ② 四元数 slerp（自动走两个姿态之间的短边）：
     每步物理转角：2.0°、2.0°、2.0° ...
     全程总共绕了：20°   ← 走了物理上真正最短的那条路

  一句话：欧拉角是'给人读的报表'，四元数是'给机器算的账本'。
  报表好看，但报表上做插值、做反解、做控制，就是在薄冰上跳舞。
```

**今天收获清单：**

- "死锁"不是机械卡死，也不是陀螺仪的专利：任何用三个角度记账的方案（航空惯导、云台、机器人）都有这个点。到了点上，两个旋钮变成同一个——姿态没变，账面命令却全变了。
- 判断一种姿态表示好不好，就看三件事：**反解唯不唯一**（同一姿态会不会对上一堆数字）、**公式里有没有会踩零的分母**（条件数）、**插值顺不顺**（数字直线 ≠ 姿态直线）。欧拉角三样全踩；四元数三样全过。
- 欧拉角的病是个"点"（pitch = ±90°），但越靠近越重：89° 时放大 57 倍、89.99° 已 5730 倍——姿态解算"一抬头就发疯"大多源于此。
- 四元数"四个数记三个自由度"，多出来的一维记"绕法"：`q` 与 `-q` 是同一个姿态（正着转 359° = 反着转 1°）。更新公式 `q ← normalize(q ⊗ Δq)` 到处可用，没有奇点。
- 工程惯例：**账本（解算/积分/插值/控制）用四元数，报表（界面/日志/给同事讲）翻译成欧拉角**；只在最后一步翻译，别拿翻译稿回去再算。
- 插值算法自带"抄近路"陷阱：数字插值可能绕 340° 的远路，slerp（含 q/-q 短边判断）才是 20° 的正路。

## ✨ 今日一句

> "死锁"不是物理把门锁上了，而是描述方法在某个角度上塌了。坐标是给自己配的眼镜，不是和物理世界签的合同——眼镜有盲区，门一直都在。换一副眼镜（四元数），锁就消失了。
