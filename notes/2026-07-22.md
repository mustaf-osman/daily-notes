## 💭 技术随想

今天想聊聊 **Shell 脚本的健壮性**。很多人写脚本上来就是 `#!/bin/bash` 然后直接开干，但一个好的习惯是在开头加上：

```bash
set -euo pipefail
```

这三面旗帜分别代表：
- **`-e`**：任何命令返回非零退出码就立即停止（别假装一切正常继续跑）
- **`-u`**：引用了未定义的变量就报错（打错变量名立刻发现）
- **`pipefail`**：管道中任何一个命令失败了，整个管道就算失败（否则只看最后一个命令的状态）

加上这三行，能拦截 90% 的"脚本明明跑了但结果不对"的诡异 bug。

## 🧩 今日代码片段

一个实用的 Python 装饰器：**自动重试失败的操作**

```python
import time
import functools

def retry(max_attempts=3, delay=2, backoff=2):
    """自动重试装饰器：失败后等待并重试"""
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            attempt, wait = 0, delay
            while attempt < max_attempts:
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    attempt += 1
                    if attempt == max_attempts:
                        raise
                    print(f"⚠️ {func.__name__} 失败 (第{attempt}次): {e}")
                    print(f"   {wait}秒后重试...")
                    time.sleep(wait)
                    wait *= backoff
            return None
        return wrapper
    return decorator

# 使用示例
@retry(max_attempts=5, delay=1, backoff=2)
def fetch_data(url):
    # 可能因为网络波动失败的操作
    ...
```

**适用场景**：网络请求、数据库连接、文件锁——任何可能因外部原因临时失败的操作。
