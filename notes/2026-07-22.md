3|## 💭 技术随想
4|
5|今天想聊聊 **Shell 脚本的健壮性**。很多人写脚本上来就是 `#!/bin/bash` 然后直接开干，但一个好的习惯是在开头加上：
6|
7|```bash
8|set -euo pipefail
9|```
10|
11|这三面旗帜分别代表：
12|- **`-e`**：任何命令返回非零退出码就立即停止（别假装一切正常继续跑）
13|- **`-u`**：引用了未定义的变量就报错（打错变量名立刻发现）
14|- **`pipefail`**：管道中任何一个命令失败了，整个管道就算失败（否则只看最后一个命令的状态）
15|
16|加上这三行，能拦截 90% 的"脚本明明跑了但结果不对"的诡异 bug。

20|一个实用的 Python 装饰器：**自动重试失败的操作**
21|
22|```python
23|import time
24|import functools
25|
26|def retry(max_attempts=3, delay=2, backoff=2):
27|    """自动重试装饰器：失败后等待并重试"""
28|    def decorator(func):
29|        @functools.wraps(func)
30|        def wrapper(*args, **kwargs):
31|            attempt, wait = 0, delay
32|            while attempt < max_attempts:
33|                try:
34|                    return func(*args, **kwargs)
35|                except Exception as e:
36|                    attempt += 1
37|                    if attempt == max_attempts:
38|                        raise
39|                    print(f"⚠️ {func.__name__} 失败 (第{attempt}次): {e}")
40|                    print(f"   {wait}秒后重试...")
41|                    time.sleep(wait)
42|                    wait *= backoff
43|            return None
44|        return wrapper
45|    return decorator
46|
47|# 使用示例
48|@retry(max_attempts=5, delay=1, backoff=2)
49|def fetch_data(url):
50|    # 可能因为网络波动失败的操作
51|    ...
52|```
53|
54|**适用场景**：网络请求、数据库连接、文件锁——任何可能因外部原因临时失败的操作。
