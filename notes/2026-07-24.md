## 💭 技术随想

今天聊聊 **Python 的 `pathlib`——用面向对象的方式告别字符串路径**。

如果你还在用 `os.path.join()`、`os.path.exists()` 和字符串拼接来操作路径，`pathlib` 是 Python 3.4+ 标准库中给你的一颗糖，值得认真用起来。它把路径变成对象，用 `/` 运算符拼接路径，代码可读性直接上一个台阶：

| 传统方式 | pathlib 方式 |
|---------|-------------|
| `os.path.join(dir, "sub", "file.txt")` | `Path(dir) / "sub" / "file.txt"` |
| `os.path.exists(p)` | `Path(p).exists()` |
| `os.listdir(dir)` | `Path(dir).iterdir()` |
| `glob.glob("**/*.py")` | `Path().rglob("*.py")` |

更棒的是 `pathlib` 在处理**跨平台路径分隔符**时完全自动适应——Windows 上用 `\`，Linux/macOS 上用 `/`，你完全不用操心。每次在 `os.path` 里手动判断 `os.sep` 的日子该结束了。

**我的个人建议**：新项目一律用 `pathlib`，老项目重构时顺手换成 `Path` 对象。标准库、第三方库（pandas、Django、FastAPI 等）全都在拥抱它，没有理由拒绝。

## 🧩 今日代码片段

一个能让你每天节省几秒钟的实用函数：**用 `pathlib` 快速定位项目根目录（支持 Git 仓库自动感知）**。

```python
from pathlib import Path
from typing import Optional

def find_project_root(marker: str = ".git", start: Optional[Path] = None) -> Path:
    """
    从当前文件/目录向上回溯，找到包含 marker 文件的目录。
    默认从调用位置往上找 .git 目录 → 项目根目录。
    也适用于 .gitignore、pyproject.toml、package.json 等标志文件。
    """
    current = (start or Path(__file__).resolve().parent)
    for ancestor in current.parents:
        if (ancestor / marker).exists():
            return ancestor
    # 没找到就返回当前目录
    return current

# 实用场景 1：自动定位项目根目录，构建绝对路径
ROOT = find_project_root()
DATA_DIR = ROOT / "data"
LOGS_DIR = ROOT / "logs"

print(f"📁 项目根目录: {ROOT}")
print(f"📊 数据目录:   {DATA_DIR}")
print(f"📝 日志目录:   {LOGS_DIR}")

# 实用场景 2：配合 Path.walk() (Python 3.12+) 统计项目文件
if hasattr(Path, "walk"):
    total_size = sum(
        f.stat().st_size for f, _, _ in ROOT.walk("*.py")
    )
    py_files = sum(1 for _ in ROOT.rglob("*.py"))
    print(f"🐍 Python 文件数: {py_files}, 总大小: {total_size / 1024:.1f} KB")
```

**亮点**：`Path.parents` 是自动向上的生成器，`Path.rglob("*.py")` 等价于 `glob("**/*.py")`，而 Python 3.12+ 的 `Path.walk()` 比 `os.walk` 更简洁。代码能直接跑，替换里面的 `.git` 为 `pyproject.toml` 就能用于纯 Python 项目。
