## 💭 技术随想：I2C 总线——两根线，一板子芯片，凭什么不乱套

一块典型的板子上，气压计、温度计、EEPROM、电源管理芯片、小小的 OLED 屏……全都挂在同样的**两根线**上：一根 SCL（时钟），一根 SDA（数据）。没有片选线、没有使能脚，也没有"每个芯片单独拉一根线"的排场——就两根，像楼道里共用的一条水电井，所有住户全接在里头。问题立刻就来：两根线连着一堆芯片，凭什么"找谁"、"谁先说"、"说完了没有"，不会乱成一锅粥？

第一层答案在**电气**上：这两根线都是**开漏（open-drain）**，各配一只上拉电阻。开漏的意思是，设备接在线上的"手"，一辈子只会两个动作——**把线拉低**，或者**松手**。注意：没有任何设备能"把线推高"；线要变高，全靠上拉电阻这只"看不见的手"把它拽上去。只要还有任意一个设备拉着不放，整根线就是低。这套规矩叫**线与**（wired-AND）。

为什么非要这么"憋屈"？因为它救了命：要是两个设备都"推挽"（既能推高、又能拉低），一个想 1、一个想 0，就是同一根线上你往上抬、我往下拽——短路、发热、烧端口。开漏把"往上抬"这份工作收归上拉电阻独家承包，所有人都只准"踩低或者松手"，于是**谁也打不死谁**，爱挂几个挂几个。还白赚两件事：多主机同时开口时，比谁先"松手"就分出了胜负（仲裁）；从机嫌节奏太快，可以按住时钟不放（拖堂）——这两件事后面都会见到。

上拉电阻的取值是门小账：太大了，线被拽起来像"慢动作"，上升沿画成圆弧（示波器上那排"鲨鱼鳍"）；太小了，低电平时白白淌直流电流。所以 4.7 kΩ 左右是标准模式（100 kHz）的常客，快速模式（400 kHz）得换 2.2 kΩ 上下——档位越高，方波的"肩"越圆不起。总线电容也有配额（400 pF 量级的总线），线拉太长、挂太密，最后都要算到这笔头上。

第二层规矩是**时间**。数据交谈有条铁律：**SDA 只许在 SCL 低的时候改变；SCL 一高，SDA 必须稳住**——因为对方就是在 SCL 变高的这一刻"取样"的。既然平时跳变都被禁止了，跳变本身就升格成了标点：SCL 高时 SDA 往下跳 = **START**（敲门）；SCL 高时 SDA 往上跳 = **STOP**（告辞）。一句话：**数据可以商量，标点必须守规矩。**

第三层规矩是**点名**。每个从机出厂就带着一个 7 位门牌号（常用区间 0x08～0x77）。主机开口第一句永远是"(地址 << 1) | 读写位"，8 个位放上线，全场安静，只有一个设备会突然坐直——就是被叫到的那位。它必须立刻回话：第 9 拍把 SDA 拉低，这就是 **ACK**（回铃）；若是没人应声，线上留个高电平，就是 **NACK**。新手第一个坑就在这：嘴上说的"地址 0x50"，总线跑的是 0xA0（写）或 0xA1（读），差一个左移；第二个坑是"双胞胎"——同型号器件的门牌靠 A0/A1/A2 脚拨号，接错线，两个设备的地址就撞了。

大多数 I2C 器件还是"寄存器堆"：想读第 0x10 号寄存器，先得说"找你（写模式）、指针拨到 0x10"，然后**不松口**，直接换方向："还是我，这次读"——这就是**重复起始**（Sr）。为什么不用"STOP 再 START"断个句？因为 STOP 一发，总线就"下班"了：别的（主）设备随时可能抢先开口；而且不少器件手册明确要求用重复起始来接续指针，STOP 之后的行为"No guarantee"。规矩就是规矩。

还有一条别家没有的温柔条款：**从机可以"拖堂"**。数据没准备好，它就把 SCL 按住不放——主机想升时钟，发现线死活起不来，只能半拍半拍地等。这叫**时钟拉伸**（clock stretching），读作"等等我"。不过这给主机立了条硬规矩：**必须看线，不能看表**——真真切切监视 SCL 的实际电平，而不是自顾自打节拍。USB 转 I2C 的小棒子很多不支持（或支持得不好）拉伸；现场表现就是"偶发超时、查不出所以然"，示波器里某个 SCL 周期被莫名拉长——那就是从机在拖堂。

速度档位一层层往上：100 kHz（标准）、400 kHz（快速）、1 MHz（Fast-mode Plus）、3.4 MHz（高速）。每上一档，上升沿的要求就更苛刻、上拉就得再小、线就得再短。工具生态也熟门熟路：Linux 上一套 `i2c-tools` 走天下（`i2cdetect` 扫一遍，`i2cget`/`i2cset` 点读点写）；MCU 端各家外设名字五花八门（nRF5340 上叫 TWIM），别管名字，手册的时序图才是唯一真相。

最后，讲一个每个调板子的人都该背下来的"急救术"，也是今天的主角——**总线被按死了怎么办**。经典事故：主机跑到一半被复位，从机恰好卡在"一个字节还没说完"的当口，SDA 被它按着、等下一个时钟。新上电的主机一看：SCL 高、SDA 低——按规矩这是"总线忙"，谁也别想开工。此时去读线，SDA 永远是 0：数据读出来全是 0x00；更阴的是"扫描"都会演戏——ACK 拍也被按低，看起来**每个地址都像有个设备**（幽灵 ACK）。"明明没接线却扫出一排器件"的灵异事件，源头大多在这。标准处方干脆利落：**只打时钟、放开 SDA，最多九个脉冲，再来一个 STOP**——让从机把"没说完的半句话"说完（最多 8 个数据位 + 1 个 ACK 拍），再用 STOP 把全场的状态机拍回待命。九个脉冲之后 SDA 还不松手？那就不是"没说完"，是硬件病：查短路、查供电，必要时给从机断电重启。

回头看，I2C 的智慧就三句话：**谁都只准把线拉低、不准推高**（电气上打不起来）；**数据只在钟低时改、标点只在钟高时跳**（时间上抢不了话）；**被叫到要回铃、跟不上可以拖堂**（交互上不用猜）。两根线，一板子芯片，装下的全是一套"克制"的秩序。SPI 确实更快、UART 确实更简单，但"一根线一个朋友"的排场，在这个从传感器到电源都挤在一张小板上、接口引脚比黄金还贵的世界里，真给不起——所以 I2C 干脆承认"线是公用的"，然后把"公用"两个字，写成了厚厚的规矩。

## 🧩 今日代码片段：一台 I2C 总线模拟器——五组现场实验

纸上推理一千遍，不如亲手把波形打出来。下面这台模拟器把 I2C 的规矩逐条翻译成代码：两根线都是"开漏线"，任何设备只能 `drive`（拉低）或 `release`（放手），线的电平 = 各方"线与"的结果；主机负责全部时序动作；每个动作采样两个"半拍"，最后把波形直接画在终端里。五组实验：① 写一个字节的逐拍波形；② 寄存器写 + 重复起始读 + 时间账；③ NACK 现场；④ 时钟拉伸；⑤ 总线死锁与九个时钟的复活术。它是协议逻辑层面的教学模型——每个结论都对得上真实芯片的因果，但别拿它算时序精度的纳秒账。

```python
# -*- coding: utf-8 -*-
"""I2C 总线模拟器：两根线的语言 —— 五组现场实验（真实可运行）

模型：一根 I2C 总线 = 两根开漏线（SCL / SDA）。
开漏 = 每个设备对线只有两种动作——"拉低"或者"放手"；高电平永远由上拉电阻提供。
只要还有一个人拉着低，整根线就是低：这叫"线与"，也是 I2C 一切魔法的地基。
主机发起一切时序：
  START：SCL 还高时，SDA 先落下（敲门）
  数据位：SCL 低时把 SDA 摆好；SCL 高时，对方采样（一个位 = 两"半拍"）
  ACK：第 9 拍，接收方把 SDA 拉低（"收到，回个铃"）
  STOP：SCL 还高时，SDA 升起（告辞）

实验1：写一个字节 —— 逐拍波形（START + 地址 0x50·W + ACK + 数据 0xA5 + ACK + STOP）
实验2：寄存器写 + 重复起始读，附时间账（100 kHz / 400 kHz）
实验3：地址上没人 —— NACK 长什么样
实验4：时钟拉伸 —— 从机"拖堂"，主机必须等
实验5：总线死锁与复活 —— 被复位打断的"半句话"，9 个时钟的急救术
"""

import sys

try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass

HI, LO = "‾", "_"
BIT_100K_US = 10.0     # 100 kHz：1 位 = 10 µs
BIT_400K_US = 2.5      # 400 kHz：1 位 = 2.5 µs


class Wire:
    """开漏线：谁都能来拉，任何人拉低，线就是低；人人放手，上拉给高。"""
    def __init__(self, name):
        self.name = name
        self.drivers = {}                    # 名字 -> True(按着低) / False(放手)

    def drive(self, who, pull_low=True):
        self.drivers[who] = bool(pull_low)

    def release(self, who):
        self.drivers[who] = False

    def level(self):
        return 0 if any(self.drivers.values()) else 1

    def pulling(self):
        return [w for w, v in self.drivers.items() if v]


class Bus:
    def __init__(self):
        self.scl = Wire("SCL")
        self.sda = Wire("SDA")
        self.units = []                      # 每个"时钟动作"一个单位，内含 2+ 个半拍
        self.bits = 0                        # 位槽计数（时间账用）

    def unit(self, label):
        u = {"label": (label + "  ")[:2], "cells": []}
        self.units.append(u)
        return u

    def cell(self, u):
        u["cells"].append((HI if self.scl.level() else LO,
                           HI if self.sda.level() else LO))


class Master:
    def __init__(self, bus):
        self.bus = bus
        self.log = []            # 事务解码记录
        self.name = "主机"

    # ---------- 基础动作 ----------
    def _cell(self, u):
        self.bus.cell(u)

    def _raise_scl(self, u, dev=None):
        """主机放开 SCL：没人捣乱它就该到高；
        若有从机在"拖堂"（按住 SCL），主机只能半拍半拍地干等。"""
        self.bus.scl.release(self.name)
        extra = 0
        while dev is not None and dev.holding_scl():
            self._cell(u)
            extra += 1
            dev.stretch_step()
        self._cell(u)
        return extra

    def idle(self):
        u = self.bus.unit("id")
        self._cell(u)
        self._cell(u)

    def start(self, repeated=False):
        u = self.bus.unit("S ")
        self.bus.sda.drive(self.name)        # SDA 先落（SCL 还高）
        self._cell(u)
        self.bus.scl.drive(self.name)        # SCL 再落 → START 完成
        self._cell(u)
        self.bus.bits += 1
        self.log.append("Sr" if repeated else "S")

    def stop(self):
        u = self.bus.unit("P ")
        self.bus.scl.drive(self.name)        # 先按住 SCL
        self.bus.sda.release(self.name)      # 放 SDA 升（SCL 低时升，安全）
        self._cell(u)
        self.bus.scl.release(self.name)      # 放 SCL 升 → SDA 高时 SCL 升 = STOP
        self._cell(u)
        self.bus.bits += 1
        self.log.append("P")

    def send_bit(self, val, label):
        u = self.bus.unit(label)
        self.bus.scl.drive(self.name)                       # 时钟先拉低
        self.bus.sda.drive(self.name, pull_low=(val == 0))  # 摆位：0 按低 / 1 放手
        self._cell(u)
        self._raise_scl(u)
        self.bus.bits += 1

    def send_byte(self, val, kind="", dev=None, is_addr=False, tx=False):
        for i in range(7, -1, -1):
            self.send_bit((val >> i) & 1, f"b{i}")
        self.log.append(f"0x{val:02X}{kind}")
        if dev is not None:
            if is_addr:
                dev.on_addr(tx)
            else:
                dev.on_rx_byte(val)
        return self.ack_slot_from_device(dev)

    def ack_slot_from_device(self, dev=None):
        """第 9 拍：听设备回不回铃。dev=None 时线上没人，读到高就是 NACK。"""
        u = self.bus.unit("Ak")
        self.bus.scl.drive(self.name)
        self.bus.sda.release(self.name)
        if dev is not None:
            dev.on_ack_start()               # 可能从这里开始"拖堂"
            self.bus.sda.drive(dev.name, pull_low=dev.ack_pending)
        self._cell(u)
        extra = self._raise_scl(u, dev)
        ok = (self.bus.sda.level() == 0)         # 先判读，再放手
        if dev is not None:
            self.bus.sda.release(dev.name)   # 回铃结束，放手
        self.bus.bits += 1
        self.log.append("Ak" if ok else "NAk")
        return ok, extra

    def read_bit(self, label, dev):
        u = self.bus.unit(label)
        self.bus.scl.drive(self.name)
        self.bus.sda.release(self.name)
        dev.drive_read_bit()
        self._cell(u)
        self._raise_scl(u, dev)
        v = self.bus.sda.level()
        self.bus.bits += 1
        return v

    def read_byte(self, dev):
        val = 0
        for i in range(7, -1, -1):
            val = (val << 1) | self.read_bit(f"b{i}", dev)
        self.log.append(f"0x{val:02X}")
        return val

    def ack_slot_from_master(self, ack, dev=None):
        """主机读完之后自己表态：拉低 = ACK（还要）；放手 = NAk（够了）。"""
        u = self.bus.unit("Ak")
        self.bus.scl.drive(self.name)
        self.bus.sda.release(self.name)
        if dev is not None:
            self.bus.sda.release(dev.name)   # 从机把 SDA 让给主机
        if ack:
            self.bus.sda.drive(self.name)
        self._cell(u)
        self._raise_scl(u)
        self.bus.bits += 1
        self.log.append("Ak" if ack else "NAk")


class Device:
    def __init__(self, bus, addr, regs=None, name=None):
        self.bus = bus
        self.addr = addr
        self.name = name or f"从机 0x{addr:02X}"
        self.regs = dict(regs or {})
        self.ptr = 0
        self.mode = None
        self.rx = []
        self.ack_pending = True
        self.scl_hold = 0        # >0：正在"拖堂"（按住 SCL 不放）
        self.arm_hold = 0        # 计划：下一次 ACK 时按住 SCL 多少个半拍
        self.tx_queue = []

    def on_addr(self, tx):
        self.ack_pending = True
        self.mode = "R" if tx else "W"
        self.rx = []
        if tx:
            byte = self.regs.get(self.ptr, 0xFF)
            self.tx_queue = [(byte >> i) & 1 for i in range(7, -1, -1)]

    def on_rx_byte(self, val):
        if self.mode == "W":
            if not self.rx:
                self.ptr = val
            else:
                self.regs[self.ptr] = val
            self.rx.append(val)

    def on_ack_start(self):
        if self.arm_hold:
            self.scl_hold = self.arm_hold
            self.arm_hold = 0
            self.bus.scl.drive(self.name)    # 按住 SCL，不让你升

    def holding_scl(self):
        return self.scl_hold > 0

    def stretch_step(self):
        self.scl_hold -= 1
        if self.scl_hold == 0:
            self.bus.scl.release(self.name)

    def drive_read_bit(self):
        bit = self.tx_queue.pop(0) if self.tx_queue else 1
        self.bus.sda.drive(self.name, pull_low=(bit == 0))


class StuckDevice(Device):
    """死锁现场：它正卡在一个字节的输出中途（剩下的位全是 0、SDA 被按住）。"""
    def __init__(self, bus, addr, bits_left):
        super().__init__(bus, addr)
        self.bits_left = bits_left
        self.bus.sda.drive(self.name)        # SDA 被它按着

    def recovery_step(self):
        """每来一个恢复时钟脉冲：吐一位；位吐完进 ACK 拍，把 SDA 让出来。"""
        if self.bits_left > 0:
            self.bits_left -= 1
            return False
        self.bus.sda.release(self.name)
        return True


def render(bus):
    cells = [c for u in bus.units for c in u["cells"]]
    ruler = ""
    for u in bus.units:
        ruler += u["label"] + "·" * (len(u["cells"]) - len(u["label"]))
    print("   " + ruler)
    print("SCL" + "".join(c[0] for c in cells))
    print("SDA" + "".join(c[1] for c in cells))


def fmt_us(bits):
    return (f"{bits} 个位槽 ≈ {bits * BIT_100K_US:.0f} µs @100kHz / "
            f"{bits * BIT_400K_US:.0f} µs @400kHz")

print("=" * 78)

dev = Device(bus, 0x50, name="从机 0x50")
m.idle()
m.start()

m.send_byte(0xA5, "", dev)                                        # 数据 0xA5
m.stop()
print()
render(bus)
print()
print("  解码:", "  ".join(m.log))
print("  （id=空闲 S=START b7..b0=字节位 Ak=回铃 P=STOP；每格为一个半拍：")

print("  注意 0xA0：总线上一句\"找 0x50\"实际跑的是 0xA0 = 0x50 左移一位 + 写位——")
print("  别把 7 位地址和线上字节搞混，这是新手第一个坑。")
print(f"  时间账：{fmt_us(bus.bits)}")

print()

m.idle()
m.start()
b0 = bus.bits
m.send_byte((0x50 << 1) | 0, "·W", dev, is_addr=True, tx=False)   # 0xA0：点名，要写

m.start(repeated=True)                                            # 重复起始：不松口，直接换方向
b1 = bus.bits
m.send_byte((0x50 << 1) | 1, "·R", dev, is_addr=True, tx=True)    # 0xA1：还是 0x50，这次要读
val = m.read_byte(dev)                                            # 读回 1 字节
```

**说明：**

- **开漏 + 上拉 = 线与**：所有设备只能"拉低或放手"，高电平由电阻提供——多人挂一根线永远打不起架，这也是仲裁、拖堂、回铃的共同地基。上拉是笔双向小账：太大 → 上升沿变圆（速度上不去）；太小 → 费电、低电平还容易被大电流抬得起翘。4.7 kΩ（100 kHz）/ 2.2 kΩ 上下（400 kHz）是常见配置；总线电容上限 400 pF 量级，上升时间粗算 `t_r ≈ 0.85·R·C`——线越长、挂得越多，R 就得越小来补偿，两头都是钱。
- **标点系统**：数据位只在 SCL 低时改变；SCL 高时 SDA 的跳变 = START/STOP。正因为"平时不许跳、跳了必是标点"，总线才不需要任何额外的控制线。
- **为什么是 9 拍**：一个字节 = 8 个数据位 + 1 个回铃拍。ACK 由收方拉低；NACK 有两副面孔——"没人在家"（地址没人应）和"够了"（主机读完最后一字节主动 NAk，实验2、4 的结尾都是它）。
- **地址的两副面孔**：手册写 0x50（7 位），总线跑 0xA0 / 0xA1（左移 + 读写位）；常用区间 0x08～0x77，同型号靠 A0/A1/A2 开路接地来分家；另有 10 位地址的扩展玩法，日常少见。
- **重复起始 Sr**：读寄存器的标配——写指针、换方向、不松口。好处：保住总线话语权，且器件指针按手册接续（很多器件 STOP 之后指针行为不保证）。
- **时钟拉伸**：从机按住 SCL 的"等等我"，主机必须实时读线。USB-I2C 桥多数支持不良——"偶发超时、时好时坏"先怀疑它；示波器/逻辑分析仪看到 SCL 某个周期被拉长就能实锤。
- **死锁与复活**：SDA 被按死时读到的一切都是 0（含 ACK 拍 → "幽灵设备"）；先判断总线空闲（SDA 该是高）再怪器件。急救：放开 SDA，打最多 9 个时钟（8 位 + ACK），直到 SDA 松开，再发 STOP；仍不行 → 硬件病（短路 / 供电 / 给从机断电重启）。
- **时间账**：100 kHz 下一拍 10 µs；本次模拟里"读一个寄存器"39 个位槽 ≈ 390 µs，写一个字节 20 个位槽 ≈ 200 µs——给轮询周期、系统实时性做预算时别忘了算它。400 kHz 直接快 4 倍。
- **实战清单**：① 干活前先确认总线空闲（SCL、SDA 都该是高）；② Linux 上 `i2cdetect -y 1` 先点名（RK3588 先看清 `/dev/i2c-*` 对应哪条）；③ NACK 排查顺序：地址算错没 → 供电 → 上拉电阻 → 连线 → 器件是否在待命；④ 示波器三看：方波肩部（上拉/线容）、ACK 拍、SCL 异常拉长；⑤ 很多模块自带 4.7 kΩ 上拉，芯片级器件要自己加——两边都加会并联变小，动手前先数清楚。
- **系列互文**：字节序（9-01）讲了"多字节数字谁在前"，CRC（9-10）给数据盖指纹，CAN 仲裁（9-16）是"大总线"的仲裁——今天这根 I2C 补上"板内传感器总线"这块拼图：低速、极省线，一根两根线养几十个设备，靠的正是上面这套"克制"的秩序。

## ✨ 今日一句

> 两根线，三条规矩：只准拉低、不准推高——所以打不起来；改话只在钟响前、钟响时必须算数——所以听得清；被叫到名字要答应、跟不上就说"等等我"——所以等得起。连事故救援都写进了协议：九个时钟、一记 STOP，再硬气的话，也要让对方说完最后一口气。
