## 💭 技术随想：陀螺仪和加速度计，谁也信不过——IMU 融合的"频率分工"

云台要稳，人头要转，机器人要站——所有这些事的第一步，都是回答一个特别朴素的问题：**"我现在到底仰了多少度？"**

装在头部的那颗 6 轴 IMU 里，有两个传感器能沾点边：

- **陀螺仪**测的是角速度。把角速度对时间积分，就得到角度。它反应快、噪声小，短时间内的每一次转动都记得清清楚楚——但它有个**零偏**：明明没动，它也会输出一个很小的角速度（典型值 1~3°/s）。这个小小的偏差每时每刻都在被积分，时间一长，角度就漂到不知道哪里去了。
- **加速度计**测的是比力。静止时，它感受到的就是重力，通过重力在三个轴上的投影，能反推出俯仰和横滚。它不随时间漂——但它吵，而且**一动就骗人**：云台一加速，惯性力和重力叠在一起，它会以为"重力歪了"，于是算出一个根本不存在的倾角。

一个短期准、长期漂；一个长期稳、短期吵。这不是谁的缺陷，是两种物理量的天性。**融合的全部意义，就是让它们各管一段。**

### 先把"两种坏法"变成数字

今天的实验里，我设了一颗"典型 MEMS IMU"：

- 陀螺零偏 **1.43°/s**，噪声 0.69°/s；
- 加速度计噪声 **2.9°**（静止时读数就在真值附近抖）；
- 真实轨迹是云台的慢摆（0.25Hz，±20°），第 3 秒抬头 25.8°；
- 中途安排四次"猛抬头/急刹车"，线加速度把加速度计的"重力方向"临时带偏 **20°~31.5°**。

只积分陀螺：20 秒后漂了 **28.9°**——零偏 1.43°/s × 20s ≈ 28.6°，剩下那零点几度是噪声也被一起积了进去。这不是算法笨，是**零偏被积分了 2000 次**。

只用加速度计：全程 RMS 6.0°，看起来还行，但干扰窗口的 RMS 是 **22.7°**，最大误差 **37.6°**——急刹车那一瞬间，它指着一个完全错误的方向，还理直气壮。

**两个传感器的错误不仅不一样，而且不相关**：一个随时间慢慢长，一个随运动突然爆。这正是融合能成立的前提。

### 互补滤波：一行代码做"频率分工"

最朴素也最常用的融合，是互补滤波：

```
角度 = α × (角度 + 陀螺角速度 × dt) + (1 - α) × 加速度计角度
```

拆开看就两句话：

- `角度 + 陀螺 × dt` 是"相信陀螺的预测"——它负责**高频**：手一抖、台一转，立刻跟上；
- `加速度计角度` 是"参考重力的绝对方向"——它负责**低频**：慢慢把陀螺积分出来的漂移拉回真值。

α 的大小，就是"你更信谁"的旋钮。取 α = 0.98、100Hz 时，时间常数 τ = -dt/ln(α) ≈ **0.495 秒**，截止频率约 **0.32Hz**：比 0.32Hz 快的动作听陀螺的，比它慢的姿态听加速度计的。实验成绩：全程 RMS **2.91°**，20 秒末尾误差 **0.94°**——比单独用任何一个都好得多。

但互补滤波有个"笨"的地方：α 是写死的。它不知道"这一次加速度计错得离谱"，只知道每次都分 2% 的权重给它。干扰窗口里，它被拖到最大 **13.2°**，要花大约一个时间常数才缓回来。

### 卡尔曼：让滤波器自己算"该信谁"

卡尔曼滤波把这件事做得更细。它维护两个状态：**角度**和**陀螺零偏**。

1. **预测**：用陀螺角速度（减去当前零偏估计）推进角度，同时让"我对角度的不确定度"变大；
2. **校正**：拿加速度计的角度当观测，按不确定度的比例把角度往观测方向拉——这个比例就是卡尔曼增益 K；
3. **顺便学零偏**：如果观测长期偏向一个方向，滤波器会把这笔账记到 `bias` 头上，而不是硬掰角度。

实验里，它确实把零偏学出来了：**0.0222 rad/s**，真值 0.025，误差 11%。20 秒末尾误差 **0.30°**，比互补滤波还稳。这部分完全符合预期——**卡尔曼的强项是"带模型的估计"，它能把传感器里那个说不清道不明的偏置，变成一个可观测的状态。**

但它的成绩单上还有另一行：**全程 RMS 3.86°，最大误差 19.1°**——比互补滤波还差。

原因不神秘：卡尔曼的观测噪声 R 取 0.03，对应 σ ≈ 9.9°。在它眼里，一个 20° 的测量跳变只是"2σ 的噪声"，完全在可信范围内。于是它跟着加速度计跑，把一次**线加速度干扰**当成了真实姿态变化。更糟的是，这个错误还会被记一部分到零偏状态里，污染之后的估计。

我顺手扫了一遍参数：R 从 0.0025 到 0.09、Q 取了几组，同一份剧本下最好的一组 RMS 3.48°，仍然没赢过互补滤波的 2.91°。**不是卡尔曼不行，是它的模型里没写"这时候别信加速度计"。** 模型没覆盖的故障，再优雅的滤波器也接不住。

### 新息门限：给"信不信"加一条物理判据

关键的一步在这里：**别把"传感器读数"当成只能接受或只能拒绝的黑盒，它和预测之间的差本身也是信息。**

卡尔曼里，这个差叫**新息（innovation）**：`acc - 预测角度`。正常情况下它应该很小（噪声量级）；如果它突然变成 20°，那就有两种可能：

1. 角度真的在 10ms 内跳了 20°——可那样陀螺应该先看到约 **35 rad/s** 的角速度；
2. 陀螺什么都没看到——那说明**加速度计在说谎**（线加速度、振动、安装松动）。

这次陀螺没看到，所以选 2。实现只多三行：预测照做，但校正之前先看新息，超过门限（0.2 rad ≈ 11.5°）就**只预测、不校正**。

成绩：全程 RMS **0.52°**，最大误差 **2.45°**，末尾 0.30°；20 秒里拒收了 **110 帧**（6%），正好覆盖四次干扰窗口。零偏照样学到 0.0221——因为干扰只是少数帧，干净的时候它还在学习。

门限也不是越紧越好：调到 0.15 rad，这个剧本里成绩还略好（RMS 0.51°），但真实系统里陀螺噪声和快速动作会更靠近门限，误拒的风险随之上升；放宽到 0.3 rad，20° 的干扰就有一部分混进去，最大误差回到 20.4°，几乎等于没设门限。**阈值本质上是"物理可信度"和"响应速度"的折中**，和所有工程参数一样，没有免费的最优。

### 三个反直觉的点

**一、"更聪明的算法"不一定更准。** 这场实验里，三行互补滤波（RMS 2.91°）赢了一整页卡尔曼（RMS 3.86°）。因为互补滤波的固定权重虽然笨，却是**有界的**：不管加速度计错得多离谱，它一次只让 2%。卡尔曼的增益是"算"出来的，算的依据是模型——模型漏了一种故障，它就会自信地错。

**二、门限不是作弊，是第二条信息。** 很多人觉得"拒收数据"是耍赖。其实新息本身就是一次交叉验证：陀螺和加速度计是两个独立的物理通道，它们打架时，"谁更符合物理"就是额外的判据。工程上常用的 `|a| ≈ g` 检查也是同一个思路——加速度计只在"合力等于重力"时才配谈姿态。

**三、融合的前提是误差不相关。** 如果两个传感器被同一个因素带偏——比如 IMU 装歪了 5°，或者整块板子在温漂——融合救不了你，因为两个"证人"说的是同一句假话。**标定永远在融合之前**：零偏、尺度、安装矩阵、轴间对齐，一个都不能省。

### 放远一点

- 云台、航模飞控里大量用的是互补滤波的变体：代码短、无需建模、参数直观，而且在"传感器偶尔发疯"这件事上天然鲁棒。不是因为工程师不会卡尔曼，是因为**简单方案的失效模式更好预测**。
- 卡尔曼/Madgwick/EKF 的价值在 3D 姿态、多传感器（加磁力计、编码器、视觉）融合时才会真正拉开差距；一维俯仰这个场景，确实是"杀鸡用牛刀"。
- 加速度计只能观测**重力方向**——绕重力轴的旋转（yaw）它完全看不见。头部 yaw 轴要么靠编码器，要么靠磁力计；只拿 6 轴 IMU 硬算 yaw，转两圈就不知道朝哪了。这也是为什么机器人上"俯仰/横滚"和"偏航"往往用两套不同的传感器。
- 真实工程还要处理：陀螺零偏随温度变化（冷启动和跑热了不是一个值）、振动导致的加速度计高频污染、传感器时间戳不同步、安装误差。**融合算法只负责"怎么用"，不负责"数据本身对不对"。**

## 🧩 今日代码片段：IMU 融合实验室——五种估法，一份确定性噪声

为了能反复对比，我没有接真传感器，而是写了一个**确定性的 IMU 模拟器**：真实俯仰轨迹是慢摆 + 一次抬头；陀螺读数是"真实角速度 + 恒定零偏 + 噪声"；加速度计读数是"真实角度 + 线加速度干扰 + 噪声"。噪声用固定种子的 LCG + Box-Muller 生成，每次运行输出一字不差——这样比较的就是算法，不是运气。

五种估法同场竞技：

1. **纯陀螺积分**——短期平滑，长期漂移；
2. **只信加速度计**——不漂，但吵，且怕线加速度；
3. **互补滤波**——α = 0.98，高频信陀螺、低频信加速度计；
4. **一维卡尔曼**——状态 [角度, 零偏]，R = 0.03；
5. **卡尔曼 + 新息门限**——新息超过 0.2 rad 时拒收该帧加速度计。

纯标准库，本机 Python 3.11.15 真实运行；下面的输出是真实运行结果。

```python
# -*- coding: utf-8 -*-
"""IMU 融合实验室：一个俯仰角，五种估法

纯标准库、确定性模拟（每次运行一字不差）。
一颗装在云台/头部上的 IMU，要估自己的俯仰角：
  陀螺仪：短期准，但有恒定零偏，积分越久漂得越远
  加速度计：长期不漂，但噪声大，一有线性加速度就被带偏
五种估法同场竞技：
  ① 只用陀螺仪积分
  ② 只用加速度计
  ③ 互补滤波（高频信陀螺、低频信加速度）
  ④ 一维卡尔曼（状态 = 角度 + 零偏）
  ⑤ 卡尔曼 + 新息门限（加速度计读数离预测太远就拒收）
"""
import math
import sys

try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass

LINE = "=" * 80
DEG = 180.0 / math.pi

DT = 0.01
STEPS = 2000                # 20 秒，100Hz
BIAS = 0.025                # 陀螺零偏 rad/s ≈ 1.43°/s
GYRO_SIGMA = 0.012          # 陀螺噪声 rad/s ≈ 0.69°/s
ACC_SIGMA = 0.05            # 加速度计噪声 rad ≈ 2.9°
ALPHA = 0.98                # 互补滤波系数：时间常数 ≈ 0.5s

# 线加速度干扰窗口：(起始步, 结束步, 偏差弧度)；0.35 rad ≈ 20°
DISTURB = [
    (150, 200, 0.35),       # t=1.5~2.0s  猛抬头
    (450, 460, -0.55),      # t=4.5~4.6s  突然刹车
    (900, 940, 0.35),       # t=9.0~9.4s  再次加速
    (1400, 1410, -0.55),    # t=14.0~14.1s 反向冲击
]
GATE = 0.20                 # 新息门限：偏差超过 0.2 rad ≈ 11.5° 就拒收


class RNG:
    """固定种子的 LCG + Box-Muller：保证每次运行的噪声一模一样"""

    def __init__(self, seed):
        self.x = seed & 0xFFFFFFFF
        self.spare = None

    def uniform(self):
        self.x = (self.x * 1664525 + 1013904223) & 0xFFFFFFFF
        return self.x / 4294967296.0

    def gauss(self, sigma=1.0):
        if self.spare is not None:
            v, self.spare = self.spare, None
            return v * sigma
        while True:
            u1 = self.uniform()
            u2 = self.uniform()
            if u1 > 1e-12:
                break
        r = math.sqrt(-2.0 * math.log(u1))
        a = 2.0 * math.pi * u2
        self.spare = r * math.sin(a)
        return r * math.cos(a) * sigma


def true_angle(t):
    """真实俯仰：0.25Hz 慢摆 ±20°，第 3 秒抬头 25.8°"""
    base = 0.35 * math.sin(2.0 * math.pi * 0.25 * t)
    step = 0.45 / (1.0 + math.exp(-(t - 3.0) / 0.03))
    return base + step


def true_rate(t):
    eps = 1e-5
    return (true_angle(t + eps) - true_angle(t - eps)) / (2.0 * eps)


def accel_bias(step):
    for i0, i1, amp in DISTURB:
        if i0 <= step < i1:
            return amp
    return 0.0


class Kalman:
    """经典一维 IMU 卡尔曼：状态 = [角度, 陀螺零偏]

    predict: 用陀螺的角速度推进角度，协方差跟着膨胀
    correct: 用加速度计的角度修正，同时把长期误差记到 bias 头上
    """

    def __init__(self, q_angle=0.001, q_bias=0.003, r_measure=0.03):
        self.q_angle = q_angle
        self.q_bias = q_bias
        self.r = r_measure
        self.angle = 0.0
        self.bias = 0.0
        self.P = [[1.0, 0.0], [0.0, 1.0]]

    def predict(self, rate, dt):
        self.angle += dt * (rate - self.bias)
        P = self.P
        P[0][0] += dt * (dt * P[1][1] - P[0][1] - P[1][0] + self.q_angle)
        P[0][1] -= dt * P[1][1]
        P[1][0] -= dt * P[1][1]
        P[1][1] += self.q_bias * dt

    def correct(self, measured):
        P = self.P
        S = P[0][0] + self.r
        k0 = P[0][0] / S
        k1 = P[1][0] / S
        y = measured - self.angle
        self.angle += k0 * y
        self.bias += k1 * y
        p00, p01 = P[0][0], P[0][1]
        P[0][0] -= k0 * p00
        P[0][1] -= k0 * p01
        P[1][0] -= k1 * p00
        P[1][1] -= k1 * p01


def pad(s, width):
    import unicodedata
    w = sum(2 if unicodedata.east_asian_width(c) in "WF" else 1 for c in s)
    return s + " " * max(0, width - w)


def rms(v):
    return math.sqrt(sum(x * x for x in v) / len(v))


def run():
    rng = RNG(0xC0FFEE)
    kf = Kalman()
    gated = Kalman()

    truth0 = true_angle(0.0)
    gyro_only = truth0
    acc_only = truth0
    comp = truth0
    kf.angle = truth0
    gated.angle = truth0

    names = ["陀螺积分", "只信加速度计", "互补滤波", "卡尔曼", "卡尔曼+门限"]
    errs = {n: [] for n in names}
    dist_errs = {n: [] for n in names}
    rejected = 0
    rows = []

    for i in range(STEPS + 1):
        t = i * DT
        truth = true_angle(t)
        noise_g = rng.gauss(GYRO_SIGMA) if i > 0 else 0.0
        noise_a = rng.gauss(ACC_SIGMA) if i > 0 else 0.0
        omega = true_rate(t) + BIAS + noise_g
        acc = true_angle(t) + accel_bias(i) + noise_a

        if i > 0:
            gyro_only += omega * DT
            acc_only = acc
            comp = ALPHA * (comp + omega * DT) + (1.0 - ALPHA) * acc

            kf.predict(omega, DT)
            kf.correct(acc)

            gated.predict(omega, DT)
            if abs(acc - gated.angle) < GATE:
                gated.correct(acc)
            else:
                rejected += 1

        current = {
            "陀螺积分": gyro_only,
            "只信加速度计": acc_only,
            "互补滤波": comp,
            "卡尔曼": kf.angle,
            "卡尔曼+门限": gated.angle,
        }
        disturbed = accel_bias(i) != 0.0
        for n in names:
            e = abs(current[n] - truth) * DEG
            errs[n].append(e)
            if disturbed:
                dist_errs[n].append(e)

        if i % 50 == 0:      # 每 0.5 秒打一行
            rows.append((t, truth, acc, current, disturbed))

    print(LINE)
    print("IMU 融合实验室：一个俯仰角，五种估法（20 秒，100Hz，纯确定性模拟）")
    print(LINE)
    print("  真实轨迹：0.25Hz 慢摆 ±20°，第 3 秒抬头 25.8°")
    print("  传感器：陀螺零偏 1.43°/s（不校准），加速度计噪声 2.9°")
    print("  运动干扰：四次线加速度，把加速度计的\"重力方向\"临时带偏 20°~31.5°")
    print()
    print("  " + pad("t(s)", 6) + pad("真值°", 8) + pad("加速度计°", 11)
          + pad("陀螺积分°", 11) + pad("互补°", 9) + pad("卡尔曼°", 10)
          + pad("KF+门限°", 10))
    print("  " + "-" * 76)
    for t, truth, acc, cur, disturbed in rows:
        mark = " *" if disturbed else ""
        print("  " + pad(f"{t:4.1f}", 6) + pad(f"{truth * DEG:6.1f}", 8)
              + pad(f"{acc * DEG:7.1f}", 11) + pad(f"{cur['陀螺积分'] * DEG:7.1f}", 11)
              + pad(f"{cur['互补滤波'] * DEG:6.1f}", 9)
              + pad(f"{cur['卡尔曼'] * DEG:6.1f}", 10)
              + pad(f"{cur['卡尔曼+门限'] * DEG:6.1f}", 10) + mark)
    print("  （* = 线加速度干扰窗口：这一刻加速度计读数本身就是错的）")

    print()
    print(LINE)
    print("成绩单：误差（度）")
    print(LINE)
    print("  " + pad("估法", 18) + pad("全程 RMS", 12) + pad("全程最大", 12)
          + pad("干扰窗口 RMS", 16) + pad("末尾误差(20s)", 14))
    print("  " + "-" * 72)
    for n in names:
        e, ed = errs[n], dist_errs[n]
        print("  " + pad(n, 18) + pad(f"{rms(e):.2f}", 12) + pad(f"{max(e):.2f}", 12)
              + pad(f"{rms(ed):.2f}", 16) + pad(f"{e[-1]:.2f}", 14))
    print()
    print(f"  卡尔曼学到的零偏：{kf.bias:.4f} rad/s（真值 {BIAS:.4f}）")
    print(f"  门限版学到的零偏：{gated.bias:.4f} rad/s；20 秒里拒收 {rejected} 帧加速度计数据"
          f"（{rejected / STEPS * 100:.0f}%）")
```

**今天收获清单：**

- **两种传感器的坏法不一样，正好互补：** 陀螺短期准、误差随积分时间线性增长（实验 20 秒漂 28.9°）；加速度计不漂，但噪声大、怕线加速度（干扰窗口最大 37.6°）。融合的前提是"误差不相关"。
- **互补滤波就一行：** `α(θ + ωdt) + (1-α)θ_acc`。α = 0.98 @ 100Hz 对应 τ ≈ 0.495s、截止 0.32Hz——高频信陀螺，低频信加速度计。简单、有界、鲁棒，缺点是不知道"这一次加速度计错得离谱"。
- **卡尔曼把零偏变成可观测状态：** 实验里学到 0.0222 rad/s（真值 0.025，误差 11%），末尾误差只有 0.30°。但它假设观测误差是零均值噪声——20° 的线加速度干扰在 R = 0.03（σ ≈ 9.9°）眼里只是 2σ，于是照单全收，最大误差 19.1°，反而输给互补滤波。
- **参数扫描的结论比单个结果更重要：** R 从 0.0025 到 0.09、Q 几组都试过，同一份剧本下最好 RMS 3.48°，仍没赢互补的 2.91°。**模型没覆盖的故障，靠调参补不回来。**
- **新息门限：** 用 `|加速度计角度 - 预测角度|` 做物理一致性检查。10ms 内真跳 20° 需要约 35 rad/s 的角速度，陀螺没看到就说明是加速度计被线加速度骗了。门限 0.2 rad、拒收 6% 的帧，RMS 从 3.86° 降到 0.52°，最大误差从 19.1° 降到 2.45°。
- **门限是折中：** 0.15 rad 在这个剧本里成绩略好（RMS 0.51°），但越靠近门限，真实快速动作被误拒的风险越高；0.3 rad 太松（20° 干扰混进来，最大误差回到 20.4°）。阈值要用"物理可信度"来定，不能拍脑袋。
- **yaw 是另一回事：** 加速度计只能观测重力方向，绕重力轴的旋转它看不见。头部的 yaw 轴要靠编码器或磁力计；6 轴 IMU 硬算 yaw，转两圈就迷路。
- **标定在融合之前：** 零偏、尺度、安装矩阵、轴间对齐、时间同步——两个传感器如果被同一个安装误差带偏，融合只会把同一个错误平均得更自信。

## ✨ 今日一句

> 陀螺记得每一秒的变化，却记不住自己从哪里出发；加速度计知道哪里是"下"，却分不清自己是歪着，还是被推着。融合的智慧，不是找一个更可信的，而是让记得变化的人管短跑、让知道方向的人管长跑——再在两人吵架时，用物理常识判断该听谁的。
