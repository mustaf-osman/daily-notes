# 📅 2026年11月06日 日报

## 💭 技术随想：采样定理不是"两倍就够"，是"采慢了会变成另一个信号"

前几天在一条腿上看到一个 30 Hz 的抖动。查了 PID、查了机械间隙、查了舵机死区，都没有。最后发现那个抖来自 IMU 里的一个高频振动：控制环每拍读一次 IMU，拍频 100 Hz，而机械上有一段 130 Hz 的共振——**130 Hz 被 100 Hz 的采样折叠成了 30 Hz，一个完全合法的、看起来很真实的低频信号。**

这就是混叠（aliasing）最让人不舒服的地方：它不产生噪声、不产生毛刺，它产生一个**假的、干净的、和你想要的东西一样规范的低频信号**。你后面所有基于"这个信号是真的"的分析，全建在一个幻觉上。

今天把它拆成了几件能算清的事：折叠怎么算、为什么救不回来、两倍到底够不够、抽取前为什么必须先低通。环境 Windows 11 / Python 3.11.15 / numpy 2.4.3，数字都是本机跑出来的。

### 一、折叠：一张表就够

采样率 $f_s$，真实频率 $f$，你看到的频率是

$$f_{\text{alias}} = \left|\, (f + f_s/2) \bmod f_s - f_s/2 \,\right|$$

取 $f_s = 1000$ Hz：

| 真实频率 | 100 | 200 | 300 | 400 | 500 | 600 | 700 | 800 | 900 | 1000 |
|---|---|---|---|---|---|---|---|---|---|---|
| 表现成 | 100 | 200 | 300 | 400 | 500 | **400** | **300** | **200** | **100** | **0** |

三件事：

1. **500 Hz 以下分毫不差。** 这就是奈奎斯特那半根线，只要信号在 $f_s/2$ 以内，采样不会骗你。
2. **过了 500 Hz，频率开始"往回走"。** 600 Hz 看起来像 400，900 Hz 看起来像 100——注意：**高频会伪装成低频。**
3. **1000 Hz 变成 0。** 频率正好等于采样率的信号，被采成了一个**常数**。它不是变小了，是变成了"直流"。

### 二、两个最狠的例子：变成直流，和变成 0

实测（$f_s = 1000$ Hz，取前 8 个采样点）：

```text
f = 1000 Hz  ->  表现成 0 Hz      ← 变成常值偏置
f =  500 Hz  ->  采样值全是 0      ← 信号整体消失
```

- **正好等于 $f_s$ 的干扰，会折叠成直流偏置。** 1 kHz 的开关电源纹波采进 1 kHz 的采样里，得到的是一个**恒定的偏置**。这种 bug 最难查：你以为是传感器零漂，标定一次，偏置还在，因为它是活的、跟你一起采进来的。
- **正好等于 $f_s/2$ 的信号，采出来是"取决于相位的幅度"。** $f_s/2$ 的正弦在采样点上就是 $\sin(\pi n + \varphi) = (-1)^n \sin\varphi$，逐点验证：

```text
相位 φ=0.0000 -> 采样序列全是 0.0          （完全消失）
相位 φ=0.3000 -> 峰值幅度 0.2955
相位 φ=0.5000 -> 峰值幅度 0.4794
相位 φ=1.5708 -> 峰值幅度 1.0000
相位 φ=2.0000 -> 峰值幅度 0.9093
```

**同一个频率、同一个幅度的信号，仅仅因为相位不同，采出来的幅度从 0 到 1。** 频率信息**百分之百丢失**，剩下的只是一个"幅度取决于运气"的常幅振荡。这就是"两倍采样率"这句话真正的分量：$\frac{f_s}{2}$ 不是"安全线"，是**悬崖边缘**。

### 三、为什么事后救不回来

上面的逻辑上可以再推一步，我把它逐点验证了。取 $f_s = 1000$ Hz 采一个信号 $x = \sin(2\pi\cdot 5t) + \sin(2\pi\cdot 62t)$，然后每 10 个点取一个（抽取，降到 100 Hz）。62 Hz 折叠到 $|62-100| = 38$ Hz。

抽取后的频谱：

```text
5.0 Hz   幅度 1.0000
38.0 Hz  幅度 1.0000      ← 和真信号一样强，一点没衰减
```

然后把这个抽样序列，和一个**凭空造出来的** 38 Hz 序列逐点比（$x = \sin(2\pi\cdot5k/100) - \sin(2\pi\cdot38k/100)$）：

```text
最大逐点差 = 7.72e-14      ← 数值精度内完全一样
```

**38 这个假信号，和一个真实的 38 Hz 信号，在数据里是两个完全相同的对象。** 不是"相似"，是逐点相同。你对假信号做的任何低通、任何滤波、任何拟合——真信号也会被一模一样地对待。**因为它们就是同一个东西。**

对抽取后的信号再补一次 30 Hz 低通：38 Hz 能压到 0.0026——**但真实存在的 38 Hz 内容也会被一起压掉。** 混叠的麻烦不在"信号被污染了"，在"污染出来的东西长得和真信号一模一样，你没有一把尺子能把它们分开"。

### 四、那"采两倍"到底够不够

课本说"$f_s > 2f$ 就能无失真还原"。这句话在数学上对，在工程上有个隐藏前提：**还原用的是无限长的 sinc 插值。** 真实的插值器是有限的。

固定 $f_s = 1000$ Hz，用一个截断的 sinc 插值器重建正弦，量它在采样点之间的误差（Hamming 窗，抽头数从 8 到 256）：

| 信号频率 | 占奈奎斯特 | 8 抽头 | 16 | 32 | 64 | 128 | 256 |
|---|---|---|---|---|---|---|---|
| 50 Hz | 10% | 4.1e-3 | 8.9e-4 | 8.1e-4 | 3.2e-4 | 2.3e-4 | 5.2e-5 |
| 250 Hz | 50% | 3.1e-3 | 1.3e-3 | 9.6e-4 | 5.2e-4 | 2.6e-4 | 1.3e-4 |
| 400 Hz | 80% | 1.5e-1 | 6.5e-3 | 4.5e-4 | 2.3e-5 | 6.7e-4 | 2.1e-4 |
| 450 Hz | 90% | 3.3e-1 | 1.5e-1 | 5.7e-3 | 6.2e-4 | 2.0e-4 | 6.1e-4 |
| 490 Hz | 98% | 5.2e-1 | 4.7e-1 | 3.8e-1 | 2.2e-1 | 3.3e-2 | 9.3e-4 |
| 499 Hz | **100%** | 6.3e-1 | 6.2e-1 | 6.1e-1 | 5.9e-1 | 5.5e-1 | **4.6e-1** |

两句话：

- **在 10% 奈奎斯特处，8 个抽头的小插值器就够用**（误差 4e-3）；到 98% 奈奎斯特，128 个抽头也才 3e-2，256 个抽头才勉强压到 9e-4。**越靠近奈奎斯特，同样的插值器误差越爆炸。** 这就是"带宽要留余量"的数学本质：奈奎斯特是理论边界，工程上要的是它的一半甚至十分之一。
- **紧贴边界的信号，256 抽头都还原不出来**（499 Hz 那一行，误差还在 0.46）。别把信号放在离 $f_s/2$ 只差一点点的地方，那里不是"能用"，是"数学上存在但物理上做不出来"。

所以实际工程里的经验数字是 **5 ~ 10 倍过采样**：如果信号带宽是 100 Hz，就采 1 kHz，而不是 200 Hz。多出来的采样率不是浪费，是**给插值器、给抗混叠滤波器留出来的施工余量**。

### 五、抽取（降采样）：先低通，而且要在原来的采样率上低通

把 1 kHz 的数据降到 100 Hz，是遥测和日志里天天要做的事。直接每 10 个点取一个（$x[::10]$）就是我第三节干了的事——**如果原信号里有超过 50 Hz 的成分，它们会全部折叠进来。**

用同一个信号（5 Hz + 62 Hz，$f_s = 1000$，抽 10 倍到 100 Hz），前面加不同类型的抗混叠滤波器：

| 抽取前的处理 | 5 Hz（要保留） | 38 Hz 假信号 | 假信号电平 |
|---|---|---|---|
| 不加滤波（直接抽） | 1.0000 | 1.0000 | **-0.0 dB** |
| 10 点滑动平均 | 0.9958 | 0.4788 | -6.4 dB |
| 101 抽头 Hamming sinc，截止 40 Hz | 1.0022 | 0.0069 | **-43.2 dB** |

- **不加滤波：假信号满血通过**，-0.0 dB，一点没衰减。
- **滑动平均只压了 6.4 dB**——很多人拿移动平均当"抗混叠"，它其实是个很差的低通（见下节）。
- **一个正儿八经的 FIR 低通（截止 40 Hz，101 抽头）把假信号压到 -43 dB**，而要保留的 5 Hz 几乎无损（0.996 → 1.002）。

正确顺序永远是：**高采样率采 → 在原始采样率上低通到新奈奎斯特以内 → 再抽取。** 顺序反了（先抽后滤），折叠已经发生，滤不回来。

### 六、滑动平均当抗混叠，到底有多差

移动平均（$M$ 点）的幅频响应是

$$|H(f)| = \left|\frac{\sin(\pi f M / f_s)}{M \sin(\pi f / f_s)}\right|$$

$f_s = 1000$、$M = 10$ 时，在 62 Hz 上算出来是 $0.48$，也就是 **-6.4 dB**，和实测的 -6.4 dB 对上了。为什么这么差：移动平均的**第一个零点在 $f_s/M = 100$ Hz**，也就是说它在 100 Hz 以内基本不衰减，只有到 100 Hz 才开始压。**它的"通带"比你想的宽得多，而折叠正是发生在 $f_s/2$ 附近那些它几乎不管的频率上。**

移动平均能去掉一些高频噪声的**观感**，但它不是抗混叠滤波器。要抗混叠，就得用真正的低通（Butterworth / Chebyshev / 窗函数设计的 FIR），把 $f_s/2$ 当成它的**阻带起点**来设计，而不是当成通带终点。

### 七、和手上的东西对上

- **控制环的采样率，决定了你"看到的世界"。** 100 Hz 的控制环，能无歧义看见的最高频率是 50 Hz。任何比这快的振动，都会伪装成一个比它慢的信号进来。**调 PID 之前先确认：这个抖动是物理的，还是采样的。** 分辨方法很土但有效：把采样率翻倍再测一次——**真信号的频率不动，混叠信号的频率会跳**。
- **IMU 和电机电流采样点要错开。** 两路 ADC 用同一个时钟在同一时刻采，一旦有接近 $f_s$ 的共模干扰，两路会得到**相关性极强的假信号**（都折叠成同一个直流），看起来像"真实存在的耦合"。物理上错开半个采样周期，就能把这种伪相关打散。
- **ADC 前面必须有模拟抗混叠滤波器。** 数字滤波器只能在采样之后干活，而采样那一刻折叠已经发生了。**一个简单的 RC 低通（截止设在 $f_s/2$ 的一半到三分之一）就能挡住绝大部分混叠**，这是硬件要做的，软件补不了。
- **CAN / 串口遥测做降采样时，先低通再取点。** 现在很多地方是"每 N 帧存一帧"，等价于 $x[::N]$——**直接抽，等于把总线上的高频噪声全部折进你要的低频数据里。** 至少加个滑动平均（虽然只有 -6 dB），最好加个 FIR。
- **编码器/轮速的采样率要配得上分辨率。** 轮速靠单位时间内的脉冲数算，采样率低的时候，"转速"这个量本身就在混叠：两个采样点之间转过多少圈，你只知道个总数，不知道中间的过程。
- **nRF5340 的 ADC/定时器**：采样定时器的触发频率就是 $f_s$，它一旦定下来，**超过 $f_s/2$ 的一切都在骗你**。上电配 ADC 之前先把抗混叠 RC 的截止频率和采样率一起算一遍，别等现场发现"数据在抖"再回来改硬件。

一句话收今天：**采样定理保证的不是"你能看见真实信号"，是"你能看见的信号里，没有一个能骗过你"——前提是，你先在物理世界里把 $f_s/2$ 以上的东西挡掉。** 挡不掉，它就会变成一个更慢、更干净、更像真的假信号的形态，出现在你的数据里。

## 🧩 今日代码片段：折叠计算 + 抗混叠抽取

`alias_freq`（算折叠到哪里）、`fir_lowpass`（Hamming 窗 sinc 线性相位低通）、`decimate`（先低通再抽取的安全版本）。下面这段是真跑过的，输出贴在后面。

```python
# -*- coding: utf-8 -*-
"""sampling：折叠计算 + 抗混叠抽取（真跑过）"""
import numpy as np


def alias_freq(f, fs):
    """真实频率 f 在采样率 fs 下会表现成什么频率（折叠到 [-fs/2, fs/2]）"""
    return abs(((f + fs / 2) % fs) - fs / 2)


def fir_lowpass(cutoff, fs, taps):
    """Hamming 窗 sinc 低通（线性相位 FIR）。cutoff 是 -6 dB 截止频率，taps 建议奇数。"""
    m = np.arange(taps) - (taps - 1) / 2
    fc = cutoff / fs
    h = 2 * fc * np.sinc(2 * fc * m)
    h *= np.hamming(taps)
    return h / h.sum()          # 归一化：通带增益为 1


def decimate(x, fs, factor, cutoff=None):
    """安全的降采样：先在原采样率上低通，再抽取。

    cutoff 默认取新奈奎斯特的 0.8 倍，给滤波器留过渡带。
    直接 x[::factor] 是不行的——高频会被折叠进来。
    """
    fs_new = fs / factor
    if cutoff is None:
        cutoff = 0.8 * fs_new / 2
    taps = 101                  # 抽头数按截止频率和采样率调整，这里固定演示用
    h = fir_lowpass(cutoff, fs, taps)
    return np.convolve(x, h, mode="same")[::factor], fs_new


if __name__ == "__main__":
    import sys
    try:
        sys.stdout.reconfigure(encoding="utf-8")
    except Exception:
        pass

    FS = 1000.0
    t = np.arange(0, 1.0, 1 / FS)
    x = np.sin(2 * np.pi * 5 * t) + np.sin(2 * np.pi * 62 * t)   # 5 Hz 要，62 Hz 不要

    def amp(sig, fs, f):
        S = np.abs(np.fft.rfft(sig)) * 2 / len(sig)
        F = np.fft.rfftfreq(len(sig), 1 / fs)
        return S[np.argmin(np.abs(F - f))]

    print("62 Hz 在 100 Hz 采样率下折叠到 %.0f Hz" % alias_freq(62, 100))

    y_naive = x[::10]
    print("直接抽：    5 Hz %.4f | 38 Hz %.4f" % (amp(y_naive, 100, 5), amp(y_naive, 100, 38)))

    y_safe, fs_new = decimate(x, FS, 10)
    print("先滤再抽：  5 Hz %.4f | 38 Hz %.4f  (%.1f dB)"
          % (amp(y_safe, fs_new, 5), amp(y_safe, fs_new, 38),
             20 * np.log10(max(amp(y_safe, fs_new, 38), 1e-12))))
```

实测输出：

```text
62 Hz 在 100 Hz 采样率下折叠到 38 Hz
直接抽：    5 Hz 1.0000 | 38 Hz 1.0000
先滤再抽：  5 Hz 1.0022 | 38 Hz 0.0069  (-43.2 dB)
```

三个值得说的细节：

- **`alias_freq` 用了取模而不是减法。** `f % fs` 只处理 \(f > f_s\) 的情况，处理不了 \(f\) 落在 \((f_s/2, f_s)\) 之间的折叠。加上 `fs/2` 再取模再减回来，才把所有频率都折进 \([-f_s/2, f_s/2]\)。
- **`fir_lowpass` 最后一定要归一化（`h / h.sum()`）。** 不然通带增益不是 1，你会以为信号真的变大了或者变小了——**滤波器不该改变你信号的大小，只该改变它的频率成分。**
- **`decimate` 里 `cutoff` 默认取新奈奎斯特的 0.8 倍**，是给滤波器留过渡带：理想砖墙不存在，真实的低通从通带到阻带需要一段斜坡。**截在 0.8 而不是 1.0，就是承认自己不是理想滤波器。**

## ✨ 今日一句

> 采样定理保证的不是"你能看见真实信号"，是"你看见的每个信号都骗不过你"——而那要等到你先在物理世界里，把 $f_s/2$ 以上的东西挡掉。
