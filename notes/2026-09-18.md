## 💭 技术随想：PWM——只会"开"和"关"的引脚，怎么调出"半速"和"半亮"

芯片的引脚大多是个倔脾气：要么 3.3V，要么 0V，没有中间档。可我们要它干的活儿，全是"中间档"——电机别全速、灯别全亮、舵机别走极端。一个只有两档的开关，凭什么造出无限级的旋钮？答案朴素得惊人：**不调幅度，调时间**。

想象一个不懂"半开"的老式水龙头，手柄只有全开和全关。但你一秒内把它开开关关一百次，拿桶接水——接到的水量完全取决于"开着的时间占几成"：开九成接九成，开一成接一成。PWM（Pulse Width Modulation，脉冲宽度调制）就是这个"拼手速"的活儿：一秒里让引脚开多久、关多久，用"开的时间占比"（占空比）冒充一个本来不存在的"中间电压"。

它凭什么骗得过负载？因为负载都很"迟钝"：电机转子有惯性，电容里存着电，人眼有视觉暂留——谁都没法跟上微秒级的开关，只能感受到平均。就像把灯以每秒上万次的速度开关，人眼只觉得灯"半亮"。工程上还会再补一刀：并一个电容（RC 滤波）把脉冲的棱角磨平，剩下那一点点起伏叫**纹波**——频率越高，纹波越小，"平均值"就越真。

看第三个实验那张表就明白：同样 50% 占空比，50Hz 时纹波能到 6V（电源的一半），这时说"等效 6V"纯属自欺；上到 5kHz，纹波不到 1%，"平均"才名正言顺。所以频率是个三方妥协：**高**了纹波小、不闪、啸叫被推出人耳；**低**了开关损耗小、EMI 老实、驱动不烫。工程惯例因此很清楚：舵机固定 50Hz，LED 调光至少几百 Hz 起，电机驱动 16k~20kHz 左右（贴着 20kHz 人耳上限打）。

最后有个著名特例：**舵机虽然也是 PWM 控制的，但它根本不看占空比**——50Hz 的周期里，它只量那根脉冲的**宽度**：1.5ms 居中，收窄到 0.5ms 是一个极端，放宽到 2.5ms 是另一个极端。占空比才在 2.5%~12.5% 之间晃，控制的却是 ±90° 的转角。这一点搞混，调舵机时会非常迷惑："我都 90% 占空比了怎么还不转过去？"——因为它量的从来不是比例，是绝对时间。

## 🧩 今日代码片段：三张图看清 PWM——占空比、舵机脉宽、频率与"平均"的成立条件

三段实验：① 把占空比画成方块，看它怎么"数出"平均电压；② 舵机的 50Hz 特例——五根不同宽度的脉冲就是五个角度；③ 同一个 50%，频率从 50Hz 换到 20kHz，用纹波公式看"平均值"从哪一刻起才站得住脚。

```python
# -*- coding: utf-8 -*-
"""PWM 演示：引脚只会"开/关"，怎么调出"平均值"

实验1：占空比 → 平均电压（ASCII 波形）
实验2：舵机特例——50Hz 里那根脉冲的宽度就是角度
实验3：同一个 50% 占空比，换频率——"平均"从哪一刻开始成立
"""
import sys
try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass

VCC = 12.0

def wave(duty, cols=46):
    hi = round(duty * cols)
    return "█" * hi + "·" * (cols - hi)

print("=" * 72)
print("实验1：占空比 = 时间上的浓度；平均电压 = 占空比 × 电源电压")
print("=" * 72)
print(f"电源 {VCC:.0f}V。引脚只有 0V / {VCC:.0f}V 两档、没有中间态——只能靠'开'的时间占比说话：")
print()
for duty in (0.0, 0.25, 0.50, 0.75, 1.00):
    v_avg = duty * VCC
    tag = {0.0: "← 一直关：0V，不转", 0.5: "← 一半时间开：等效 6V",
           1.0: "← 一直开：全速"}.get(duty, "")
    print(f"  {duty*100:>3.0f}%  |{wave(duty)}|  {v_avg:>5.1f}V  {tag}")
print()
print("  （█=开，·=关。开关够快时，负载只感知到平均值。）")

print()
print("=" * 72)
print("实验2：舵机是特例——50Hz 周期（20ms）里，只看那根脉冲有多宽")
print("=" * 72)
P_MIN, P_MAX = 0.5, 2.5          # 常见规格：0.5ms ~ 2.5ms 对应 -90° ~ +90°
A_MIN, A_MAX = -90.0, 90.0

def angle(pulse_ms):
    return A_MIN + (pulse_ms - P_MIN) / (P_MAX - P_MIN) * (A_MAX - A_MIN)

print(f"规格：{P_MIN}~{P_MAX}ms ↔ {A_MIN:.0f}°~{A_MAX:.0f}°（不同舵机看手册，1.5ms 是居中）")
print("画前 4ms（每格 0.1ms），后面 16ms 一直低电平：")
print()
for pulse in (0.5, 1.0, 1.5, 2.0, 2.5):
    hi = round(pulse * 10)       # 每 0.1ms 一格，画 40 格 = 4ms
    bar = "█" * hi + "·" * (40 - hi)
    a = angle(pulse)
    print(f"  {pulse:>3.1f}ms |{bar}|…  →  {a:>+5.1f}°   (占空比 {pulse/20*100:>4.1f}%)")
print()
print("  → 占空比在 2.5%~12.5% 之间晃，控制的是 ±90° 的转角——舵机量的是'脉宽'本身，")
print("    不是比例；周期换成 10ms 或 30ms，这几根宽度含义基本不变。")

print()
print("=" * 72)
print("实验3：同一个 50% 占空比，换频率——'平均'从哪一刻开始成立")
print("=" * 72)
R_OHM, C_F = 100.0, 100e-6       # τ = R×C = 10ms
TAU = R_OHM * C_F
d = 0.5
print(f"负载前面加个 RC 滤波：R={R_OHM:.0f}Ω，C={C_F*1e6:.0f}µF → τ={TAU*1000:.0f}ms")
print("纹波估算：Vpp ≈ Vcc × d × (1-d) × T / τ  —— 开关越快，留下的浪花越小")
print()
print(f"{'频率':>7} | {'周期 T':>10} | {'纹波 Vpp':>9} | {'占 12V 比例':>10}   备注")
print("-" * 68)
notes = {
    50:    "← 老式频闪：灯肉眼看得出闪",
    100:   "← 相机慢门能拍到灯条",
    500:   "← LED 调光的常用起点",
    1000:  "← 纹波进 2% 级",
    5000:  "← 电机驱动常用档",
    20000: "← 逼近人耳上限，最安静",
}
for f in (50, 100, 500, 1000, 5000, 20000):
    T = 1.0 / f
    vpp = VCC * d * (1 - d) * T / TAU
    print(f"{f:>5}Hz | {T*1000:>8.3f}ms | {vpp:>7.3f}V | {vpp/VCC*100:>8.2f}%   {notes[f]}")
print()
print("  → 同样一个'50%'：50Hz 时纹波高达 6V（电源的一半），'平均值'是个笑话；")
print("    上到 5kHz，纹波不到 1%——这时说'它就是 6V'才站得住脚。")
print("  → 频率也不是越高越好：开关损耗、EMI、驱动发热都随频率涨，够用就行。")
print()
print("一句话：PWM = 用时间换数值——两个死板的档位，靠'开多久'平均出整个世界。")
```

**说明：**

- 实验 1 想让你记住一句话：**数字里没有"中间值"，中间值是平均出来的**。0/25/50/75/100% 五档对应 0/3/6/9/12V；对直流有刷电机来说，转速大致就跟着这个平均电压走（空载近似）。
- "平均"能不能成立，取决于负载的"迟钝程度"：机械惯性、电容、视觉暂留都是天然的滤波器；反过来，如果负载比开关还快（比如拿示波器直接看），那它看到的就是一列方波，根本没有"6V"这回事。**调功率前先问一句：负载反应得过来吗？**
- 实验 3 的公式值得记：`Vpp ≈ Vcc × d × (1-d) × T / (RC)`——纹波与周期 T 成正比（频率翻倍就减半），并且在 **d = 50% 时最大**。最常用的中间值恰恰是纹波最凶的档位；两头极端的占空比反而干净，因为"几乎不开关"。
- 频率怎么选，一张小抄：舵机 50Hz 固定；LED 调光 ≥ 几百 Hz（上到 1kHz 以上基本绝迹闪烁）；电机/开关电源 16k~20kHz 躲听觉；再往上就要为开关损耗、EMI、驱动发热付代价。
- 舵机特例再强调：数据手册写的是"脉宽范围"（比如 500~2500µs），不是占空比；周期在 10~30ms 之间换，脉宽的含义基本不变——它认的是**绝对时间**。新手按百分比调舵机，越调越迷惑，坑就在这。
- 再往深一层：舵机内部的小控制器、电机驱动器里的 H 桥 MOSFET、开关电源的 buck 电路……最终输出给执行器的都是"快速开关"，PWM 是它们的共同语言。接口从"一根脉冲线"升级成串口/CAN 报文之后，省掉的只是线，这门母语没变。
- 落地清单：① 调功率先确认"负载反应得过来吗"，再定频率和要不要 RC；② 舵机按脉宽 ms 算角度，别按百分比；③ 占空比寄存器位宽 = 分辨率（8 位 256 档 / 16 位 65536 档），要精细就上 16 位；④ 电机发热和啸叫二选一时，往 16kHz 以上挪，往往两个问题一起解决。

## ✨ 今日一句

> 开关只会说"开"和"关"两个字。PWM 的办法是把它说得足够快——快到电机、灯珠和眼睛，都以为它说的是"一半"。
