5|今天想聊聊 **SQLite 在非嵌入式场景下的威力**。很多人一听 SQLite 就觉得"那是给手机 App 用的玩具数据库"，但事实上 SQLite 在以下场景表现极其出色：
6|
7|- **数据分析脚本的存储层**：跑一次爬虫或 ETL 后把结果写进 SQLite，比 CSV 强一百倍——支持 SQL 查询、索引、事务，而且就一个文件，拷到哪里都能用。
8|- **本地开发/测试**：用 SQLite 替代 PostgreSQL/MySQL 做单元测试，速度翻倍、0 配置、测试完删文件就行。
9|- **CLI 工具的数据持久化**：比如一个命令行记账工具，用 SQLite 存储，比 JSON/YAML 方案更可靠（事务保证写入不损坏）。
10|- **数据归档**：5 年后你想查某个历史数据集，一个 `.sqlite` 文件打开就能查，比跑 Docker 起数据库省心太多。
11|
12|但要注意：**高并发写入**（几十个连接同时写）、**大规模多用户**这些场景还是交给专用数据库。选对工具，SQLite 是个被严重低估的宝贝。

14|## 🧩 今日代码片段

16|一个超级实用的 Python 工具函数：**递归查找当前项目中的循环导入（circular import）嫌疑点**。不过今天推荐一个更轻松的——用纯 Python 写一个简易终端进度条，不依赖 tqdm：
17|
18|```python
19|import time
20|import shutil
21|
22|class ProgressBar:
23|    """简易终端进度条，零依赖"""
24|    def __init__(self, total, prefix='进度', suffix='完成', length=None, fill='█'):
25|        self.total = total
26|        self.prefix = prefix
27|        self.suffix = suffix
28|        self.length = length or shutil.get_terminal_size().columns - 20
29|        self.fill = fill
30|        self.current = 0
31|
32|    def update(self, n=1):
33|        self.current += n
34|        percent = self.current / self.total
35|        filled_len = int(self.length * percent)
36|        bar = self.fill * filled_len + '─' * (self.length - filled_len)
37|        print(f'\r{self.prefix} |{bar}| {percent:.1%} {self.suffix}', end='\r')
38|        if self.current >= self.total:
39|            print()
40|
41|# 使用示例
42|total = 50
43|bar = ProgressBar(total, prefix='🔄 处理中')
44|for i in range(total):
45|    time.sleep(0.05)   # 模拟耗时操作
46|    bar.update()
47|```
48|
49|**亮点**：自动检测终端宽度、支持自定义填充字符、零外部依赖。当你需要在受限环境（Docker 容器、无 pip 权限的服务器）中跑脚本时，这个比 `tqdm` 更轻便。
