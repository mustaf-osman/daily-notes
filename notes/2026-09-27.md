## 💭 技术随想：采样定理——车轮为什么倒着转，800Hz 为什么装成 200Hz

你肯定见过这样的画面：电影里马车飞驰，车轮却在慢悠悠地倒转。不是穿帮，也不是错觉——这是"采样"披着魔术外衣办的一堂课。

胶片每秒只拍 24 张。假如车轮每秒转 23 圈，两张快照之间它其实向前转了 345°。可看快照的人（大脑也算）不会去数圈数，只会挑"最省力"的解释：345° 和"倒着转 15°"落在同一个位置上——于是车轮倒转了起来。转速从 24 降到 23 只差 4%，银幕上却从"定格"变成了"慢慢倒转"；再升到 25，又变成慢慢正转。眼睛和胶片都没坏，是"从有限张快照反推连续真相"这件事本来就有无穷多个解，而直觉总挑最省力的那个。

信号的世界里，ADC 就是那台按快门的高速摄影机：每秒按 fs 次，记一笔"此刻电压是多少"。拿 1000Hz 去采一个 800Hz 的正弦：两个采样点之间，它的相位悄悄走过了 0.8 圈。快照不数圈数，只记位置——"多转 0.8 圈"和"少转 0.2 圈"在位置上毫无区别，于是这串数字与一段 200Hz 低频波形逐点重合，一个数都不差。

这就是奈奎斯特-香农采样定理的两张脸。**正面**：只要 fs 大于信号最高频率的两倍，快照序列就能唯一还原出原始波形——"2 倍"因此成为数学底线。**反面**更值得警惕：一旦有超过 fs/2 的成分混进来，它不会老实消失，而是按 |f − k·fs| 的公式"折叠"回来，伪装成一段低频（800Hz → 200Hz，2800Hz 也 → 200Hz……无穷多个"真身"共用同一串快照）。这个现象叫**混叠**（aliasing）——名字起得极准：一个频率"混"进了不该在的频段，冒用别人的身份。

关键在"不可逆"三个字。折叠发生在采样那一瞬间；采样之后，真 200Hz 和假 200Hz 是同一串数字——数字滤波再高明也分不开，因为它们之间已经不存在任何能区分彼此的"信息"。就像你无法从每帧一幅简笔画里反推车轮真正转了多少度：超出整圈的部分，在快门按下的一刻就被丢掉了。所以抗混叠滤波器必须装在 ADC **之前**（模拟域），在门口就把 fs/2 以上的东西滤干净——保安要站门外，不能等小偷进了屋才查证件。

工程里到处是这条规矩的影子：CD 音频人耳上限 20kHz，采样率定 44.1kHz——40k 只是底线，多出来的 4.1k 是留给滤波器从"通过"到"拦住"的缓冲坡道；电机 FOC 的电流采样要和 PWM 同步，专挑开关噪声最小的时刻采，否则噪声会被混叠成"假电流纹波"，控制器对着幻影使劲；IMU 采样不足时，真实的高频振动会伪装成低频漂移，变成那种"换个采样率就变形"的怪毛病。反过来，示波器的等效采样、软件无线电的带通采样，是**故意**欠采样——把射频信号"折"进普通 ADC 能测的低频段。混叠是事故还是手艺，取决于你知不知道自己在采样什么。

落地口诀三句：2 倍是数学底线，不是工程目标（控制回路常见 5~10 倍）；带外没滤干净之前，别相信任何一个采样数字；找不到原因的"低频怪现象"，先怀疑混叠——它最爱伪装成你最不设防的那个频率。

## 🧩 今日代码片段：三个实验看清"混叠"——同一串快照，无穷多个真相

三段实验：① 200 / 800 / 1200 / 1800 / 2200 / 2800 Hz 六个频率共用同一串 1000Hz 快照，逐点对照 + 折叠公式；② 马车轮效应——345°/帧 被读成 −15°/帧 的取模算术，23 / 24 / 25 转每秒的三种命运；③ 采样率选择对照表 + 欠采样彩蛋（故意翻车的手艺）。

```python
# -*- coding: utf-8 -*-
"""采样定理与混叠演示：拍得不够快，快动作就会"倒着演"（真实可运行）

实验1：同一串快照，六个频率——采样之后，数学上再也分不出谁是真身
实验2：马车轮效应——每帧 345° 会被读成 -15° 的取模算术
实验3：采样率怎么选 + 欠采样彩蛋
"""
import math
import sys

try:
    sys.stdout.reconfigure(encoding="utf-8")
except Exception:
    pass

FS = 1000.0  # 采样率：每秒 1000 张"电压快照"


def snap(f, n, fs=FS):
    """频率 f(Hz) 的余弦信号，第 n 张快照的值（用余弦，避免正弦相位翻符号的干扰）"""
    return math.cos(2.0 * math.pi * f * n / fs)


def fold_alias(f, fs):
    """折叠公式：频率 f 在采样率 fs 下伪装成的频率，返回 (k, 结果)"""
    k = math.floor(f / fs + 0.5)  # 就近取整（避开 Python round 的偶数舍入）
    return k, abs(f - k * fs)


def alias(f, fs=FS):
    return fold_alias(f, fs)[1]


def fold180(deg):
    """角度折叠：任意转角折算成 (-180°, +180°] 里"最省力"的解释"""
    return ((deg + 180.0) % 360.0) - 180.0


def dotplot(vals, rows=11):
    grid = [[" "] * len(vals) for _ in range(rows)]
    for i, v in enumerate(vals):
        v = max(-1.0, min(1.0, v))
        r = int(round((1.0 - v) / 2.0 * (rows - 1)))
        grid[r][i] = "·"
    for r in range(rows):
        tag = " +1 |" if r == 0 else (" -1 |" if r == rows - 1 else "    |")
        print("  " + tag + "".join(grid[r]))
    print("     +" + "─" * len(vals))


print("=" * 76)
print("实验1：同一串快照，六个频率——采样之后，数学上再也分不出谁是真身")
print("=" * 76)
print(f"采样率 fs = {FS:.0f}Hz（每秒拍 1000 张快照）。")
print("下面六个频率各拍 5 张快照、逐点对照；最后一列是它们与 200Hz 的逐点最大差（全测 200 点）：")
print()
head = f"  {'f(Hz)':>6} | " + " | ".join(f"n={i}     " for i in range(5)) + "|| 折叠到 | 逐点最大差"
print(head)
print("  " + "-" * 84)
fams = [200, 800, 1200, 1800, 2200, 2800]
for f in fams:
    vals = " | ".join(f"{snap(f, n):+8.4f}" for n in range(5))
    md = max(abs(snap(f, n) - snap(200, n)) for n in range(200))
    print(f"  {f:>6} | {vals} || {alias(f):>4.0f}Hz | {md:.1e}")
print()
print("  六个频率：200 / 800 / 1200 / 1800 / 2200 / 2800 Hz——最后一列全是浮点噪声量级；")
print("  给定了采样率，这串数字面前六个频率完全平权，谁也没法自证真身。")
print()
print("以下把 800Hz 的 49 张快照单独画出来（纵轴：电压 -1 ~ +1）：")
dotplot([snap(800, n) for n in range(49)])
print("  ↑ 每 5 个点循环一次——在采样者眼里，它就是一条 200Hz 的慢波（1000/200 = 5 点/周期）。")
print("    真身却是 800Hz：两点之间悄悄多转了 0.8 圈。快照不数整圈，只认'离整圈差的那 0.2 圈'，")
print("    而 cos(-x) = cos(x)，差的这 0.2 圈和 200Hz 的 +0.2 圈，交出完全相同的数字。")

print()
print("=" * 76)
print("实验2：马车轮效应——每帧 345° 被读成 -15°（与信号折叠同一道取模算术）")
print("=" * 76)
print("影片 24 帧/秒。真实转速 f_rot（转/秒）→ 每帧车轮实际转过 θ = 360·f_rot/24 度。")
print("眼睛（和胶片）只挑'最短的那段弧'解释：把 θ 折进 (-180°, +180°]。")
print()
print(f"  {'真实转速':>10} | {'每帧实际':>8} | {'目视转角':>8} | 观众看到")
print("  " + "-" * 66)
special = {
    23: "慢慢倒转 ★（经典马车轮效应）",
    24: "定格不动 ★（每帧刚好一整圈）",
    25: "慢慢正转 ★（只比 23 快 2 转/秒）",
}
for fr in (6, 12, 15, 23, 24, 25, 36, 48, 49):
    th = 360.0 * fr / 24.0
    ap = fold180(th)
    if fr in special:
        verdict = special[fr]
    elif abs(ap) < 1e-9:
        verdict = "定格不动（每帧若干整圈）"
    elif abs(abs(ap) - 180.0) < 1e-9:
        verdict = "完全无法辨认（每帧恰好半圈）"
    elif ap < 0:
        verdict = "倒着转"
    else:
        verdict = "正着转"
    print(f"  {fr:>10} | {th:>7.0f}° | {ap:>+7.0f}° | {verdict}")
print()
print("  → 相邻两档（23/24/25）真实转速只差 1 转/秒（≈4%），银幕上却是三种命运：倒转、定格、正转。")
print("  → 345° ≡ -15°（mod 360°）；0.8 圈 ≡ -0.2 圈（mod 1 圈）——轮子与正弦，栽在同一道算术上。")

print()
print("=" * 76)
print("实验3：采样率怎么选——2 倍是数学底线，不是工程目标")
print("=" * 76)
print()
print("  场景         内容最高频率   理论底线(2×)   工程余量(5×)   现实里的选择")
print("  " + "-" * 74)
rows3 = [
    ("电话语音", 3400, "ITU 8kHz 标准：话带先被压到 3.4k 以内"),
    ("CD 音乐", 20000, "44.1kHz：40k 是底线，多出的 4.1k 给滤波器过渡"),
    ("电机电流环", 1000, "随 PWM 同步采（16~20kHz），控制带宽远低于 fs/2"),
]
for name, fm, note in rows3:
    print(f"  {name:<12}{fm:>8}Hz{fm * 2:>11}Hz{fm * 5:>12}Hz   {note}")
print()
print("  注：2× 是数学底线（理想低通前提下）；实际留几倍，取决于模拟滤波器有多陡、")
print("      带外还有多少东西——控制环常见 5~10 倍，音频、通信则按各自标准来。")
print()
print("  彩蛋：采样不足不总是事故，有时是门手艺——欠采样（带通采样）")
f1, f2, fsr = 5300.0, 3300.0, 2000.0  # 单位: kHz
k1, a1 = fold_alias(f1, fsr)
k2, a2 = fold_alias(f2, fsr)
print(f"    真实信号 {f1 / 1000:.1f}MHz：|{f1:.0f} - {k1:.0f}×{fsr:.0f}| = {a1:.0f}kHz")
print(f"    真实信号 {f2 / 1000:.1f}MHz：|{f2:.0f} - {k2:.0f}×{fsr:.0f}| = {a2:.0f}kHz")
print("    → 同一个 700kHz，背后站着两个（其实是无穷多个）'真身'；")
print("      被'折'进低频段正是软件无线电、示波器等效采样的手艺——故意欠采样，专测射频。")
print()
print("一句话：快照的密度决定你能看见哪个世界；不够密的时候，世界会挑一个最省力的说法骗你。")
```

**说明：**

- 实验 1 记住一句话：**采样之后，频率只是"快照的无穷多个解释"之一**。六个频率与 200Hz 的逐点差全在 1e-13 量级——那是浮点运算的最后一位，不是差异。给定了采样率，真身无法自证，这是"反问题没有唯一解"的最简实例。
- 折叠公式值得背下来：`f_obs = |f − k·fs|`（k 取最近整数）；伪装家族是 `k·fs ± f` 全体：800 = 1×1000−200、1200 = 1×1000+200、2800 = 3×1000−200……全部折回 200Hz。一个细节：用正弦演示时，"k·fs − f"那一侧会带一个负号（相位翻转）；余弦没有这个问题，所以演示用余弦——但频率的"身份"两种情况下都分不开。
- 车轮和正弦栽在同一道算术上：345° ≡ −15°（mod 360°）；0.8 圈 ≡ −0.2 圈（mod 1 圈）。"挑最短的那段弧"和"折叠回 [0, fs/2]"，本质是同一种"最省力解释"。23 / 24 / 25 转每秒的三种命运（倒转、定格、正转）就是模运算相邻的三个点——真实世界只差 4%，感知世界差了一个方向。
- 混叠的可怕之处是**不可逆**：它发生在采样那一瞬间，之后真 200Hz 与假 200Hz 是同一串数字，不存在能区分它们的信息。抗混叠滤波器必须在 ADC 之前、并且是模拟电路；数字域的一切事后补救都救不回这一刀。
- 采样率怎么选：2× 是理想低通下的数学底线，工程留几倍取决于滤波器有多陡、带外还有多少东西（控制环常见 5~10 倍）。三个参照：电话 8kHz（话带先被压进 3.4k）、CD 44.1kHz（40k + 4.1k 过渡带）、FOC 16~20kHz 与 PWM 同步——每个数字都是"底线 + 滤波器 + 场景"的组合，不是拍脑袋。
- "故意欠采样"是门正经手艺：5.3MHz 和 3.3MHz 用 2MSPS 采，都折叠成 700kHz——软件无线电、示波器等效采样靠它用普通 ADC 测射频。代价：单次测量只给出"折叠值"，解出唯一真身要靠先验知识或第二个采样率。
- 呼应 PID 那篇：传感器数据一旦被混叠"污染"，PID 调得再好也是在对一个幻觉闭环——先保证看到的信号是真的，再谈控制。排障口诀：**换个采样率它就变形的"低频怪现象"，基本就是混叠**。
- 落地清单：① ADC 前端一律先放抗混叠滤波；② 采样率 ≥ 5× 关心带宽（数学底线 2×）；③ 关键采样（电机电流）与 PWM 同步；④ 怀疑混叠时，用第二个采样率复核——真信号的频率不会跟着采样率跑。

## ✨ 今日一句

> 采样器从不记圈数，只记位置。快门不够密的时候，世界会撒一个自洽的谎——于是全力奔跑的马车倒转着车轮，800Hz 披上 200Hz 的皮。
