3|## 💭 技术随想
4|
5|今天聊聊 **Python `dataclasses`**——一个在 Python 3.7 引入、能让你的代码量减少一半的神器。
6|
7|写过很多「纯粹用来装数据」的类吗？`__init__`、`__repr__`、`__eq__` 三板斧轮着写，类体里全是样板代码。`dataclasses` 就是为了解决这个问题而生的：你只需要声明字段，`__init__`、`__repr__`、`__eq__`、`__hash__` 等方法自动生成，零样板代码。
8|
9|但 dataclasses 的真正威力远不止「少写几行代码」这么简单。几个我最喜欢的高级特性：
10|
11|1. **`frozen=True`**：让实例不可变，等同于定义了 `__setattr__` 和 `__delattr__` 的冻结版本，天然适合作为配置对象或字典键
12|2. **`field(default_factory=...)`**：对 list/dict/set 这种可变默认值，用工厂函数而非直接赋值，彻底告别「可变默认值陷阱」
13|3. **`__post_init__`**：初始化后自动调用的钩子方法，适合做字段校验、派生字段计算
14|4. **继承支持**：子类 dataclass 会自动合并父类的字段，且字段按 MRO 顺序排列
15|5. **配合 `typing`**：泛型、Optional、Literal 都能用，类型检查一把抓
16|
17|`namedtuple` 能做的，dataclass 都能做且做得更好——它可变（除非 `frozen=True`）、支持类型注解、可继承、可自定义方法。是时候全面拥抱 dataclasses 了。
18|
19|## 🧩 今日代码片段
20|
21|一个实用的 dataclass 示例：**构建一个简易的配置管理器**，支持从环境变量、YAML 文件、默认值三层回退加载配置，自动校验类型。
22|
23|```python
24|from dataclasses import dataclass, field, fields
25|from typing import Optional
26|import os
27|import json
28|from pathlib import Path
29|
30|
31|# 一、基础 dataclass：自动生成 __init__ / __repr__ / __eq__
32|@dataclass(frozen=True)
33|class DatabaseConfig:
34|    """数据库连接配置（不可变，防止运行时误改）"""
35|    host: str = "localhost"
36|    port: int = 5432
37|    database: str = "app"
38|    username: str = "app_user"
39|    password: str = field(default="", repr=False)  # repr=False 避免密码泄露
40|    pool_size: int = field(default=10, repr=False)
41|
42|    # 初始化后校验
43|    def __post_init__(self):
44|        if not (1 <= self.port <= 65535):
45|            raise ValueError(f"端口号 {self.port} 超出有效范围")
46|        if self.pool_size < 1:
47|            raise ValueError(f"连接池大小必须 >= 1，收到 {self.pool_size}")
48|
49|
50|# 二、嵌套 dataclass + 字段默认值工厂
51|@dataclass
52|class AppConfig:
53|    """应用配置，从多个来源加载"""
54|    app_name: str = "my-app"
55|    debug: bool = False
56|    db: DatabaseConfig = field(default_factory=DatabaseConfig)
57|    allowed_hosts: list[str] = field(default_factory=lambda: ["*"])
58|    feature_flags: dict[str, bool] = field(default_factory=dict)
59|
60|    def __post_init__(self):
61|        if isinstance(self.db, dict):  # 兼容 JSON/YAML 反序列化
62|            self.db = DatabaseConfig(**self.db)
63|
64|
65|# 三、带层级回退的配置加载器
66|@dataclass
67|class ConfigLoader:
68|    """配置加载器：环境变量 → JSON 文件 → 默认值"""
69|    config_dir: str = "config"
70|    env_prefix: str = "APP_"
71|
72|    def load(self, env: str = "development") -> AppConfig:
73|        config = AppConfig()  # 1️⃣ 默认值
74|
75|        # 2️⃣ 尝试从 JSON 文件覆盖
76|        config_file = Path(self.config_dir) / f"{env}.json"
77|        if config_file.exists():
78|            with open(config_file, encoding="utf-8") as f:
79|                overrides = json.load(f)
80|            # 只覆盖显式指定的字段（保留默认值）
81|            for fld in fields(config):
82|                if fld.name in overrides:
83|                    setattr(config, fld.name, overrides[fld.name])
84|
85|        # 3️⃣ 环境变量优先级最高（覆盖文件中的值）
86|        for fld in fields(config):
87|            env_key = f"{self.env_prefix}{fld.name.upper()}"
88|            if env_key in os.environ:
89|                raw = os.environ[env_key]
90|                # 根据字段类型做简单转换
91|                if fld.type is bool:
92|                    setattr(config, fld.name, raw.lower() in ("1", "true", "yes"))
93|                elif fld.type is int:
94|                    setattr(config, fld.name, int(raw))
95|                else:
96|                    setattr(config, fld.name, raw)
97|
98|        return config
99|
100|
101|# 四、使用示例
102|if __name__ == "__main__":
103|    # 直接创建
104|    cfg = DatabaseConfig(host="prod.example.com", port=5432, pool_size=20)
105|    print(cfg)  # DatabaseConfig(host='prod.example.com', port=5432, database='app', ...)
106|
107|    # 不可变特性
108|    try:
109|        cfg.host = "other.com"
110|    except AttributeError as e:
111|        print(f"❌ 不可修改: {e}")
112|
113|    # 自动校验
114|    try:
115|        DatabaseConfig(port=99999)
116|    except ValueError as e:
117|        print(f"❌ 校验拦截: {e}")
118|
119|    # 嵌套 + 回退加载
120|    loader = ConfigLoader(config_dir="configs")
121|    app_cfg = loader.load("production")
122|    print(f"✅ 应用名: {app_cfg.app_name}")
123|    print(f"✅ DB 配置: {app_cfg.db}")
124|```
125|
126|**小贴士**：如果你还在用 Python 3.6 及以下（应该升级了！），可以用 `attrs` 库作为替代，它功能更丰富（验证器、转换器、slots 等），但 dataclasses 是标准库——零依赖、零学习成本。从今天起，所有「数据容器」类都试试 `@dataclass` 吧！

128|## ✨ 今日一句
129|
130|> **"Simplicity is prerequisite for reliability."**
131|>
132|> 简单是可靠的前提条件。
133|>
134|> —— Edsger W. Dijkstra
135|>
136|> dataclasses 的哲学正是如此：用最少的代码表达最清晰的数据结构。当你移除所有样板代码后，剩下的就是真正的业务逻辑——而那才是软件中真正复杂、需要你专注的部分。Python 社区有一句话很贴切：**"Code is read more often than it is written."** 写得少，读得快，改得安全，这就是 dataclasses 给你的礼物。
