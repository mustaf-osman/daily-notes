## 💭 技术随想

今天聊聊 **Python `dataclasses`**——一个在 Python 3.7 引入、能让你的代码量减少一半的神器。

写过很多「纯粹用来装数据」的类吗？`__init__`、`__repr__`、`__eq__` 三板斧轮着写，类体里全是样板代码。`dataclasses` 就是为了解决这个问题而生的：你只需要声明字段，`__init__`、`__repr__`、`__eq__`、`__hash__` 等方法自动生成，零样板代码。

但 dataclasses 的真正威力远不止「少写几行代码」这么简单。几个我最喜欢的高级特性：

1. **`frozen=True`**：让实例不可变，等同于定义了 `__setattr__` 和 `__delattr__` 的冻结版本，天然适合作为配置对象或字典键
2. **`field(default_factory=...)`**：对 list/dict/set 这种可变默认值，用工厂函数而非直接赋值，彻底告别「可变默认值陷阱」
3. **`__post_init__`**：初始化后自动调用的钩子方法，适合做字段校验、派生字段计算
4. **继承支持**：子类 dataclass 会自动合并父类的字段，且字段按 MRO 顺序排列
5. **配合 `typing`**：泛型、Optional、Literal 都能用，类型检查一把抓

`namedtuple` 能做的，dataclass 都能做且做得更好——它可变（除非 `frozen=True`）、支持类型注解、可继承、可自定义方法。是时候全面拥抱 dataclasses 了。

## 🧩 今日代码片段

一个实用的 dataclass 示例：**构建一个简易的配置管理器**，支持从环境变量、YAML 文件、默认值三层回退加载配置，自动校验类型。

```python
from dataclasses import dataclass, field, fields
from typing import Optional
import os
import json
from pathlib import Path


# 一、基础 dataclass：自动生成 __init__ / __repr__ / __eq__
@dataclass(frozen=True)
class DatabaseConfig:
    """数据库连接配置（不可变，防止运行时误改）"""
    host: str = "localhost"
    port: int = 5432
    database: str = "app"
    username: str = "app_user"
    password: str = field(default="", repr=False)  # repr=False 避免密码泄露
    pool_size: int = field(default=10, repr=False)

    # 初始化后校验
    def __post_init__(self):
        if not (1 <= self.port <= 65535):
            raise ValueError(f"端口号 {self.port} 超出有效范围")
        if self.pool_size < 1:
            raise ValueError(f"连接池大小必须 >= 1，收到 {self.pool_size}")


# 二、嵌套 dataclass + 字段默认值工厂
@dataclass
class AppConfig:
    """应用配置，从多个来源加载"""
    app_name: str = "my-app"
    debug: bool = False
    db: DatabaseConfig = field(default_factory=DatabaseConfig)
    allowed_hosts: list[str] = field(default_factory=lambda: ["*"])
    feature_flags: dict[str, bool] = field(default_factory=dict)

    def __post_init__(self):
        if isinstance(self.db, dict):  # 兼容 JSON/YAML 反序列化
            self.db = DatabaseConfig(**self.db)


# 三、带层级回退的配置加载器
@dataclass
class ConfigLoader:
    """配置加载器：环境变量 → JSON 文件 → 默认值"""
    config_dir: str = "config"
    env_prefix: str = "APP_"

    def load(self, env: str = "development") -> AppConfig:
        config = AppConfig()  # 1️⃣ 默认值

        # 2️⃣ 尝试从 JSON 文件覆盖
        config_file = Path(self.config_dir) / f"{env}.json"
        if config_file.exists():
            with open(config_file, encoding="utf-8") as f:
                overrides = json.load(f)
            # 只覆盖显式指定的字段（保留默认值）
            for fld in fields(config):
                if fld.name in overrides:
                    setattr(config, fld.name, overrides[fld.name])

        # 3️⃣ 环境变量优先级最高（覆盖文件中的值）
        for fld in fields(config):
            env_key = f"{self.env_prefix}{fld.name.upper()}"
            if env_key in os.environ:
                raw = os.environ[env_key]
                # 根据字段类型做简单转换
                if fld.type is bool:
                    setattr(config, fld.name, raw.lower() in ("1", "true", "yes"))
                elif fld.type is int:
                    setattr(config, fld.name, int(raw))
                else:
                    setattr(config, fld.name, raw)

        return config


# 四、使用示例
if __name__ == "__main__":
    # 直接创建
    cfg = DatabaseConfig(host="prod.example.com", port=5432, pool_size=20)
    print(cfg)  # DatabaseConfig(host='prod.example.com', port=5432, database='app', ...)

    # 不可变特性
    try:
        cfg.host = "other.com"
    except AttributeError as e:
        print(f"❌ 不可修改: {e}")

    # 自动校验
    try:
        DatabaseConfig(port=99999)
    except ValueError as e:
        print(f"❌ 校验拦截: {e}")

    # 嵌套 + 回退加载
    loader = ConfigLoader(config_dir="configs")
    app_cfg = loader.load("production")
    print(f"✅ 应用名: {app_cfg.app_name}")
    print(f"✅ DB 配置: {app_cfg.db}")
```

**小贴士**：如果你还在用 Python 3.6 及以下（应该升级了！），可以用 `attrs` 库作为替代，它功能更丰富（验证器、转换器、slots 等），但 dataclasses 是标准库——零依赖、零学习成本。从今天起，所有「数据容器」类都试试 `@dataclass` 吧！
