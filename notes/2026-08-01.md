## 💭 技术随想：为什么你的 Shell 脚本总是"差一点"？

写脚本的时候，最大的坑不是语法错误，而是**状态管理**。脚本跑了一半失败了，再跑一次——是不是会把已经完成的部分搞乱？

解决方案：**幂等性（Idempotency）**。意思是"同一个操作执行一次和执行一百次，结果一样"。

```bash
# ❌ 不幂等：每次跑都追加一行
echo "export PATH=/opt/bin:$PATH" >> ~/.bashrc

# ✅ 幂等：先检查有没有，没有再追加
grep -q "/opt/bin" ~/.bashrc || echo "export PATH=/opt/bin:$PATH" >> ~/.bashrc
```

这条原则适用于：文件创建、服务启动、数据库迁移、配置写入...所有自动化场景。

## 🧩 今日代码片段：Python 的 `pathlib` 替代 `os.path`

Python 3.4+ 的 `pathlib` 比老旧的 `os.path` 好用太多：

```python
from pathlib import Path

# 老写法
import os
base = os.path.join(os.path.dirname(__file__), "data")
os.makedirs(base, exist_ok=True)
with open(os.path.join(base, "config.json")) as f:
    data = json.load(f)

# 新写法
base = Path(__file__).parent / "data"
base.mkdir(parents=True, exist_ok=True)
data = json.loads((base / "config.json").read_text())
```

**亮点：** `/` 运算符拼接路径、`.read_text()` 一行读文件、`.mkdir(parents=True)` 自动建父目录。
