## 💭 技术随想

今天聊聊 **Python 的 `pathlib`** —— 一个在 Python 3.4 就已引入、但直到今天仍有大量开发者没有充分使用的标准库模块。

传统的 `os.path` 用字符串表示路径，拼接用 `os.path.join()`，判断用 `os.path.exists()`，获取父目录用 `os.path.dirname()`——全是分散的函数调用，且返回的都是普通字符串，没有任何类型安全保障。而 `pathlib` 把所有路径操作封装在 `Path` 对象中，使用 `/` 运算符拼接路径（没错，就是除号），代码可读性直接上一个台阶。

几个我最常用的 pathlib 技巧：

1. **路径拼接**：`Path("data") / "subdir" / "file.json"` vs `os.path.join("data", "subdir", "file.json")`
2. **通配符查找**：`Path(".").glob("**/*.py")` 递归查找所有 Python 文件，返回生成器，懒加载不占内存
3. **读写文件**：`Path("file.txt").read_text()` / `.write_text()` 一行搞定，不需要手动 `open()` 和 `close()`
4. **路径属性**：`.name`、`.stem`、`.suffix`、`.parent` 清晰直观
5. **链式操作**：支持 `with_name()`、`with_suffix()` 等方法，返回新 Path 对象而不修改原对象

pathlib 让路径操作变得更**声明式**而非**指令式**——你「描述」你想要什么路径，而不是「一步步告诉计算机怎么拼」。这种思维转变，比省几行代码更有价值。

一个实用的 pathlib 脚本：**批量重命名项目目录下的所有截图文件**，给它们加上统一的日期前缀，同时展示 pathlib 的多种能力。

```python
from pathlib import Path
from datetime import date

def batch_rename_screenshots(directory: str = "screenshots",
                             prefix: str = date.today().isoformat()) -> None:
    """
    遍历指定目录下的所有 .png / .jpg 文件，
    按序号重命名为「日期-序号.后缀」格式。
    """
    base = Path(directory)
    if not base.exists():
        print(f"❌ 目录不存在: {base.resolve()}")
        return

    # 使用 glob 查找图片文件（递归寻找子目录）
    images = sorted(base.rglob("*.[pj][np]g"))  # 匹配 .png .jpg .jpeg
    if not images:
        print(f"📭 未找到图片文件")
        return

    print(f"🔍 找到 {len(images)} 个文件\n")

    for idx, img in enumerate(images, start=1):
        # 解析文件名各部分
        new_name = f"{prefix}-{idx:03d}{img.suffix}"
        new_path = img.parent / new_name  # 保持原目录结构
        img.rename(new_path)
        print(f"  ✅ {img.name:30s} → {new_name}")

    print(f"\n✨ 重命名完成，共处理 {len(images)} 个文件")


def find_duplicate_names(directory: str = ".") -> list[Path]:
    """
    查找同名但不同后缀的文件（可能有相关资源文件散落各处）。
    展示 pathlib 的链式操作。
    """
    root = Path(directory)
    # 按文件名（不含后缀）分组
    stems: dict[str, list[Path]] = {}
    for f in root.rglob("*"):
        if f.is_file():
            stems.setdefault(f.stem, []).append(f)

    # 找出有多条记录的
    return [files for files in stems.values() if len(files) > 1]


if __name__ == "__main__":
    # === 批量重命名截图 ===
    batch_rename_screenshots("screenshots")

    # === 查找同名文件 ===
    dupes = find_duplicate_names(".")
    for group in dupes:
        print(f"📎 同名文件组 ({group[0].stem}):")
        for p in group:
            print(f"     {p.relative_to(Path('.').resolve())}")
```

**小贴士**：`pathlib.Path` 兼容所有 `os.path` 函数——如果你需要调某个只支持字符串路径的旧库，直接用 `str(path_obj)` 转换即可。pathlib 不是「替代品」，而是「更好的默认选择」。从今天起，写新代码时试试 `Path` 而不是 `os.path`，你会发现路径操作不再是一件「令人烦躁的琐事」。
